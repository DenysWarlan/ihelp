# Тест-кейси: S-E16-09 — Modal компонент

## Контекст
Ця сторія реалізує модальний компонент з overlay, кількома способами закриття та підтримкою доступності. Тести перевіряють відкриття/закриття модалки (кнопка X, overlay, Escape), focus trap для keyboard navigation та наявність aria-атрибутів.

### TC-S-E16-S09-01: Відкриття та закриття модального вікна
- **Передумови:** Modal компонент реалізований
- **Кроки:**
  1. Відкрити модальне вікно
  2. Закрити кнопкою "X"
  3. Відкрити знову -> закрити кліком на overlay
  4. Відкрити знову -> закрити клавішею Escape
- **Очікуваний результат:** Modal відкривається з overlay (backdrop); закривається усіма трьома способами
- **Пріоритет:** Високий

### TC-S-E16-S09-02: Focus trap та доступність
- **Передумови:** Modal відкритий з кількома інтерактивними елементами
- **Кроки:**
  1. Натиснути Tab кілька разів
  2. Перевірити, чи фокус залишається всередині модалки
  3. Перевірити aria-атрибути
- **Очікуваний результат:** Focus trap працює — Tab-навігація обмежена всередині модалки; присутні `role="dialog"`, `aria-modal="true"`, `aria-labelledby`
- **Пріоритет:** Високий
