# Тест-кейси: S-E16-06 — Іконки (Lucide)

## Контекст
Ця сторія інтегрує бібліотеку іконок Lucide в Angular-проєкт з підтримкою параметрів size, color та stroke-width. Тести перевіряють коректний рендеринг іконок з design tokens та ефективний tree-shaking у production build.

### TC-S-E16-S06-01: Інтеграція Lucide іконок
- **Передумови:** Angular проєкт зібраний
- **Кроки:**
  1. Додати іконку Lucide у компонент
  2. Задати параметри: size, color (design token), stroke-width
  3. Перевірити рендеринг
- **Очікуваний результат:** Іконка рендериться з заданими параметрами; колір відповідає design token
- **Пріоритет:** Середній

### TC-S-E16-S06-02: Tree-shaking іконок
- **Передумови:** Production build з використанням 3-4 іконок
- **Кроки:**
  1. Зібрати production build
  2. Перевірити розмір bundle
- **Очікуваний результат:** У bundle потрапляють тільки використані іконки; невикористані відсутні
- **Пріоритет:** Середній
