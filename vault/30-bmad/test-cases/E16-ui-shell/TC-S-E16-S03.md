# Тест-кейси: S-E16-03 — Sidebar навігація (рольова)

## Контекст
Ця сторія реалізує sidebar-навігацію, яка адаптується під роль користувача (Person, Consultant, Supervisor, Coordinator, Admin). Тести перевіряють відображення коректних пунктів меню для кожної ролі та ізоляцію — Person не бачить staff-пунктів.

### TC-S-E16-S03-01: Sidebar для Person
- **Передумови:** Person авторизований
- **Кроки:**
  1. Відкрити `/my`
  2. Перевірити sidebar
- **Очікуваний результат:** Sidebar містить: Кабінет, Курси, Чат, Профіль
- **Пріоритет:** Високий

### TC-S-E16-S03-02: Sidebar для кожної ролі Staff
- **Передумови:** Акаунти з ролями Consultant, Supervisor, Coordinator, Admin
- **Кроки:**
  1. Авторизуватися як Consultant -> перевірити sidebar
  2. Авторизуватися як Supervisor -> перевірити sidebar
  3. Авторизуватися як Coordinator -> перевірити sidebar
  4. Авторизуватися як Admin -> перевірити sidebar
- **Очікуваний результат:** Consultant: Мої кейси, Профіль, Вийти; Supervisor: Всі кейси, Звіти, Кризові alerts, Вийти; Coordinator: Dashboard, Призначення, Аналітика, Вийти; Admin: Dashboard, Користувачі, Курси, Налаштування, Аудит, Вийти
- **Пріоритет:** Високий

### TC-S-E16-S03-03: Sidebar не показує чужі пункти
- **Передумови:** Авторизований Person
- **Кроки:**
  1. Перевірити sidebar
  2. Переконатися у відсутності staff-пунктів
- **Очікуваний результат:** Person НЕ бачить пунктів Consultant/Supervisor/Coordinator/Admin sidebar
- **Пріоритет:** Високий
