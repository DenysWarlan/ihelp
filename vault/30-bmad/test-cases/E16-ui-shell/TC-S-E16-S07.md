# Тест-кейси: S-E16-07 — Базові UI-компоненти (частина 1 — елементи форм)

## Контекст
Ця сторія реалізує базові UI-компоненти форм (Text Input, Select, Checkbox, Textarea, Button) з підтримкою Angular Reactive Forms. Тести перевіряють усі стани компонентів (default, hover, focus, disabled, error), інтеграцію з FormControl/FormGroup, валідаційні повідомлення та варіанти Button.

### TC-S-E16-S07-01: Стани компонентів форм
- **Передумови:** Компоненти Text Input, Select, Checkbox, Textarea реалізовані
- **Кроки:**
  1. Перевірити кожен компонент у стані: default, hover, focus, disabled, error
  2. Перевірити інтеграцію з Angular Reactive Forms
- **Очікуваний результат:** Кожен компонент коректно відображає всі стани; підтримує Reactive Forms (FormControl, FormGroup)
- **Пріоритет:** Високий

### TC-S-E16-S07-02: Валідаційні повідомлення
- **Передумови:** Text Input з required та email валідацією
- **Кроки:**
  1. Залишити поле порожнім та натиснути submit
  2. Ввести невалідний email
- **Очікуваний результат:** Під полем відображається валідаційне повідомлення при error-стані
- **Пріоритет:** Високий

### TC-S-E16-S07-03: Button — варіанти та стани
- **Передумови:** Button компонент реалізований
- **Кроки:**
  1. Перевірити варіанти: primary, secondary, danger
  2. Перевірити стани: default, hover, active, disabled, loading
- **Очікуваний результат:** Кожен варіант має візуально відмінний стиль; loading стан показує індикатор; disabled блокує натискання
- **Пріоритет:** Високий
