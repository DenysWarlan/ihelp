# Тест-кейси: S-E16-05 — Design Tokens та типографіка

## Контекст
Ця сторія реалізує систему design tokens (CSS custom properties та SCSS variables) та типографічну шкалу з self-hosted шрифтами. Тести перевіряють наявність усіх токенів, відповідність дизайн-системі, self-hosted завантаження шрифтів Inter та Geist Mono та коректну шкалу типографіки.

### TC-S-E16-S05-01: CSS custom properties для токенів
- **Передумови:** Проєкт зібраний
- **Кроки:**
  1. Перевірити наявність CSS custom properties: `--accent`, `--bg`, `--surface`, `--text`, `--error`, `--warning`, `--success`
  2. Перевірити SCSS variables як alias
  3. Перевірити відповідність значень design system у `ihelp-design.pen`
- **Очікуваний результат:** Всі токени задокументовані як CSS custom properties та SCSS variables; значення відповідають дизайн-системі
- **Пріоритет:** Високий

### TC-S-E16-S05-02: Self-hosted шрифти
- **Передумови:** Проєкт запущений
- **Кроки:**
  1. Відкрити DevTools -> Network
  2. Перевірити джерело завантаження шрифтів Inter та Geist Mono
- **Очікуваний результат:** Inter та Geist Mono завантажуються з локального сервера (self-hosted); немає запитів до Google Fonts CDN
- **Пріоритет:** Високий

### TC-S-E16-S05-03: Шкала типографіки
- **Передумови:** Проєкт зібраний
- **Кроки:**
  1. Перевірити визначення стилів h1–h6, body, small, caption
  2. Перевірити застосування Inter для UI-тексту
  3. Перевірити застосування Geist Mono для code/data
- **Очікуваний результат:** Шкала розмірів визначена для всіх рівнів; шрифти застосовуються відповідно до призначення
- **Пріоритет:** Середній
