# Тест-кейси: S-E14-01 — Landing Page

## Контекст
Ця сторія реалізує головну сторінку публічного сайту iHelp, яка слугує першою точкою контакту з відвідувачами. Тести перевіряють наявність усіх ключових елементів (hero-секція, CTA-кнопки, навбар), коректність навігаційних посилань та продуктивність сторінки на мобільних пристроях.

### TC-S-E14-S01-01: Відображення головної сторінки з усіма елементами
- **Передумови:** Користувач не авторизований (Guest)
- **Кроки:**
  1. Відкрити сторінку `/`
  2. Перевірити наявність hero-секції з описом служби
  3. Перевірити наявність CTA-кнопок та блоку переваг
- **Очікуваний результат:** Сторінка відображає hero-секцію, кнопку "Потрібна допомога" (веде на `/request`), кнопку "Переглянути курси" (веде на `/courses`) та блок переваг
- **Пріоритет:** Високий

### TC-S-E14-S01-02: Навбар містить коректні елементи
- **Передумови:** Користувач не авторизований (Guest)
- **Кроки:**
  1. Відкрити сторінку `/`
  2. Перевірити вміст навбару
- **Очікуваний результат:** Навбар містить логотип, посилання "Курси" (веде на `/courses`), кнопку "Увійти" (веде на `/login`)
- **Пріоритет:** Високий

### TC-S-E14-S01-03: Продуктивність та responsive layout
- **Передумови:** Мобільний пристрій або емуляція mobile viewport
- **Кроки:**
  1. Відкрити сторінку `/` на мобільному пристрої
  2. Виміряти LCP за допомогою DevTools
  3. Перевірити адаптивність layout
- **Очікуваний результат:** LCP < 2 секунди; layout коректно адаптується під мобільний viewport
- **Пріоритет:** Середній
