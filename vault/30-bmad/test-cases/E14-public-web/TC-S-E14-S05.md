# Тест-кейси: S-E14-05 — Форма звернення (Intake)

## Контекст
Ця сторія реалізує форму звернення на сторінці `/request`, через яку відвідувачі можуть подати запит на допомогу. Тести перевіряють успішне відправлення з різними комбінаціями GDPR-чекбоксів, валідацію email у реальному часі та обробку обов'язкових полів.

### TC-S-E14-S05-01: Успішне відправлення форми з обома чекбоксами
- **Передумови:** Користувач на сторінці `/request`
- **Кроки:**
  1. Заповнити ім'я, країну, мову, спосіб зв'язку (email), ввести валідний email
  2. Обрати тему з випадаючого списку
  3. Заповнити опис ситуації
  4. Відмітити обидва GDPR-чекбокси
  5. Натиснути "Відправити"
- **Очікуваний результат:** Care Case створюється зі статусом "нове" з темою та описом; перенаправлення на `/request/success`
- **Пріоритет:** Високий

### TC-S-E14-S05-02: Відправлення без чекбоксу Art.9 (згода на чутливі дані)
- **Передумови:** Користувач на сторінці `/request`
- **Кроки:**
  1. Заповнити всі поля коректно
  2. Відмітити тільки перший GDPR-чекбокс (обробка персональних даних)
  3. Не відмічати другий чекбокс (Art.9)
  4. Натиснути "Відправити"
- **Очікуваний результат:** Care Case створюється БЕЗ теми/опису; користувач бачить попередження про обмежену обробку; перенаправлення на `/request/success`
- **Пріоритет:** Високий

### TC-S-E14-S05-03: Форма не відправляється без першого GDPR-чекбоксу
- **Передумови:** Користувач на сторінці `/request`
- **Кроки:**
  1. Заповнити всі поля коректно
  2. Не відмічати перший GDPR-чекбокс
  3. Натиснути "Відправити"
- **Очікуваний результат:** Форма не відправляється; відображається повідомлення про необхідність надати згоду
- **Пріоритет:** Високий

### TC-S-E14-S05-04: Валідація email у реальному часі
- **Передумови:** Користувач на сторінці `/request`, спосіб зв'язку — email
- **Кроки:**
  1. Ввести невалідний email (наприклад, "test@", "test.com", "@mail.com")
  2. Перевірити реакцію форми
  3. Виправити на валідний email
- **Очікуваний результат:** При невалідному email — real-time feedback з повідомленням про помилку; форма не відправляється; після виправлення помилка зникає
- **Пріоритет:** Високий

### TC-S-E14-S05-05: Обов'язкові поля не заповнені
- **Передумови:** Користувач на сторінці `/request`
- **Кроки:**
  1. Залишити ім'я порожнім
  2. Не обрати країну
  3. Натиснути "Відправити"
- **Очікуваний результат:** Форма не відправляється; відображаються повідомлення валідації для порожніх обов'язкових полів
- **Пріоритет:** Середній
