# Тест-кейси: S-E14-02 — Каталог курсів

## Контекст
Ця сторія реалізує публічну сторінку каталогу курсів, де відвідувачі можуть переглянути доступні навчальні матеріали. Тести перевіряють відображення сітки курсів, наявність банера "Потрібна допомога?", responsive-адаптацію під різні пристрої та коректну обробку порожнього стану.

### TC-S-E14-S02-01: Відображення сітки курсів
- **Передумови:** В системі є декілька опублікованих курсів; користувач не авторизований
- **Кроки:**
  1. Відкрити сторінку `/courses`
  2. Перевірити сітку карток курсів
- **Очікуваний результат:** Сторінка відображає сітку карток з назвою, описом та кількістю уроків для кожного курсу
- **Пріоритет:** Високий

### TC-S-E14-S02-02: Банер "Потрібна допомога?"
- **Передумови:** Користувач на сторінці `/courses`
- **Кроки:**
  1. Знайти банер "Потрібна допомога?"
  2. Натиснути посилання на банері
- **Очікуваний результат:** Банер присутній, посилання веде на `/request`
- **Пріоритет:** Середній

### TC-S-E14-S02-03: Responsive layout каталогу
- **Передумови:** Різні розміри viewport (mobile, tablet, desktop)
- **Кроки:**
  1. Відкрити `/courses` на mobile (< 768px)
  2. Відкрити `/courses` на tablet (768–1024px)
  3. Відкрити `/courses` на desktop (> 1024px)
- **Очікуваний результат:** Сітка карток адаптується під кожен розмір екрану
- **Пріоритет:** Середній

### TC-S-E14-S02-04: Каталог без курсів
- **Передумови:** В системі немає опублікованих курсів
- **Кроки:**
  1. Відкрити сторінку `/courses`
- **Очікуваний результат:** Сторінка відображає порожній стан з інформативним повідомленням (без помилки)
- **Пріоритет:** Низький
