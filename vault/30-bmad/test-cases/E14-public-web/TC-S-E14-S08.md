# Тест-кейси: S-E14-08 — Responsive та доступність публічних сторінок

## Контекст
Ця сторія забезпечує responsive-адаптацію та доступність (WCAG 2.1 AA) усіх публічних сторінок. Тести перевіряють коректний layout на різних breakpoints (mobile, tablet, desktop), продуктивність (LCP < 2с) та відповідність стандартам доступності (контраст, focus states, aria labels).

### TC-S-E14-S08-01: Responsive layout всіх публічних сторінок
- **Передумови:** Доступ до пристроїв або емуляції різних viewport
- **Кроки:**
  1. Відкрити кожну публічну сторінку (Landing, Catalog, Preview, Request, Confirmation, Login) на mobile (< 768px)
  2. Повторити на tablet (768–1024px)
  3. Повторити на desktop (> 1024px)
- **Очікуваний результат:** Всі сторінки мають коректний responsive layout для кожного breakpoint
- **Пріоритет:** Високий

### TC-S-E14-S08-02: Продуктивність на мобільних пристроях
- **Передумови:** Емуляція мобільного пристрою з 3G+ з'єднанням
- **Кроки:**
  1. Відкрити кожну публічну сторінку
  2. Виміряти LCP через Lighthouse або DevTools
- **Очікуваний результат:** LCP < 2 секунди на всіх сторінках
- **Пріоритет:** Високий

### TC-S-E14-S08-03: WCAG 2.1 AA доступність
- **Передумови:** Інструмент перевірки доступності (axe, Lighthouse)
- **Кроки:**
  1. Запустити перевірку доступності на всіх публічних сторінках
  2. Перевірити контраст тексту
  3. Перевірити focus states на інтерактивних елементах
  4. Перевірити aria labels для форм та навігації
- **Очікуваний результат:** Достатній контраст (4.5:1), видимі focus states, коректні aria labels для всіх форм та навігації
- **Пріоритет:** Середній
