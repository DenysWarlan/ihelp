# Тест-кейси: S-E14-04 — Модальне вікно авторизації (Course Start)

## Контекст
Ця сторія реалізує модальне вікно авторизації, що з'являється при натисканні "Почати курс". Тести перевіряють повний флоу авторизації через OAuth з GDPR-чекбоксом згоди, блокування OAuth-кнопок без згоди, rollback при помилці OAuth та коректне скасування модального вікна.

### TC-S-E14-S04-01: Успішна авторизація та початок курсу
- **Передумови:** Користувач на превью курсу; OAuth-провайдер доступний
- **Кроки:**
  1. Натиснути "Почати курс"
  2. Відмітити чекбокс згоди на обробку даних
  3. Натиснути одну з OAuth-кнопок (Google/Facebook/Telegram)
  4. Пройти авторизацію у OAuth-провайдера
- **Очікуваний результат:** Enrollment створено; користувач перенаправлений на перший урок курсу; timestamp згоди збережено
- **Пріоритет:** Високий

### TC-S-E14-S04-02: OAuth-кнопки неактивні без чекбоксу згоди
- **Передумови:** Модальне вікно авторизації відкрите
- **Кроки:**
  1. Не відмічати чекбокс згоди
  2. Спробувати натиснути OAuth-кнопку
- **Очікуваний результат:** OAuth-кнопки неактивні (disabled); натискання не викликає жодної дії
- **Пріоритет:** Високий

### TC-S-E14-S04-03: Rollback при помилці OAuth
- **Передумови:** Модальне вікно відкрите; чекбокс згоди відмічений
- **Кроки:**
  1. Натиснути OAuth-кнопку
  2. Імітувати помилку OAuth (відхилити доступ у провайдера)
- **Очікуваний результат:** Дані згоди видаляються (rollback); enrollment НЕ створюється; користувач бачить повідомлення про помилку
- **Пріоритет:** Високий

### TC-S-E14-S04-04: Скасування модального вікна
- **Передумови:** Модальне вікно авторизації відкрите
- **Кроки:**
  1. Натиснути кнопку "Скасувати"
- **Очікуваний результат:** Модальне вікно закривається; жодних даних не зберігається; користувач залишається на превью курсу
- **Пріоритет:** Середній
