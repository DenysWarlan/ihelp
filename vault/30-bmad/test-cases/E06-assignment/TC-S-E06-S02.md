# Тест-кейси: S-E06-02 — Атомарність призначення (race condition protection)

## Контекст
Ця історія забезпечує атомарність призначення консультанта для захисту від race conditions. Тести перевіряють коректну обробку одночасного призначення останнього вільного слота через CHECK constraint та graceful обробку constraint violation з fallback.

### TC-S-E06-S02-01: Одночасне призначення останнього слота
- **Передумови:** Консультант має 1 вільний слот; два нових CareCase створюються одночасно
- **Кроки:**
  1. Два кейси одночасно намагаються призначитися цьому консультанту
- **Очікуваний результат:** Один кейс успішно призначений; другий потрапляє у fallback (без помилки для Person); CHECK constraint (current_cases < max_cases) не порушений
- **Пріоритет:** Високий

### TC-S-E06-S02-02: Constraint violation обробляється gracefully
- **Передумови:** Консультант досяг ліміту навантаження
- **Кроки:**
  1. Новий кейс намагається призначитися цьому консультанту
- **Очікуваний результат:** Кейс обробляється через fallback; Person не бачить технічної помилки
- **Пріоритет:** Високий
