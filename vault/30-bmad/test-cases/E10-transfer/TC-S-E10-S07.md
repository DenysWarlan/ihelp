# Тест-кейси: S-E10-07 — Блокування видалення консультанта з активними кейсами

## Контекст
Ця сторi блокує видалення або деактивацiю консультанта поки у нього є активнi кейси (включаючи кейси на паузi). Тести перевiряють блокування на рiвнi UI та API, облiк кейсiв на паузi та дозвiл пiсля перерозподiлу.

### TC-S-E10-S07-01: Блокування видалення при активних кейсах
- **Передумови:** Адмiн авторизований; консультант має активнi кейси
- **Кроки:**
  1. Адмiн намагається видалити або деактивувати консультанта
- **Очiкуваний результат:** Видалення/деактивацiя заблокована; адмiн бачить список кейсiв, що блокують видалення; кожен кейс має посилання для переходу
- **Прiоритет:** Високий

### TC-S-E10-S07-02: Блокування враховує кейси на паузi
- **Передумови:** Консультант має тiльки кейси в статусi "пауза"
- **Кроки:**
  1. Адмiн намагається видалити консультанта
- **Очiкуваний результат:** Видалення заблоковане; кейси на паузi включенi у список блокуючих
- **Прiоритет:** Високий

### TC-S-E10-S07-03: Видалення дозволено пiсля перерозподiлу
- **Передумови:** Адмiн ранiше не мiг видалити консультанта; всi кейси перерозподiленi
- **Кроки:**
  1. Усi кейси передано iншим консультантам
  2. Адмiн натискає "Видалити/Деактивувати"
- **Очiкуваний результат:** Видалення/деактивацiя виконується успiшно
- **Прiоритет:** Високий

### TC-S-E10-S07-04: Перевiрка на рiвнi API
- **Передумови:** Адмiн намагається видалити консультанта через прямий API-запит
- **Кроки:**
  1. Вiдправити DELETE-запит до API для консультанта з активними кейсами
- **Очiкуваний результат:** API повертає помилку (409 Conflict або 422); видалення заблоковано на рiвнi backend, а не тiльки UI
- **Прiоритет:** Середнiй
