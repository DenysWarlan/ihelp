# Тест-кейси: S-E11-07 — Рольовий доступ до аналiтики

## Контекст
Ця сторi обмежує доступ до аналiтичних дашбордiв за ролями: дозволено для Supervisor, Coordinator, Admin; заборонено для Person та Consultant. Тести перевiряють доступ дозволених ролей, блокування недозволених та обмеження видимостi для супервiзора.

### TC-S-E11-S07-01: Доступ дозволених ролей
- **Передумови:** Облiковi записи з ролями Supervisor, Coordinator, Admin
- **Кроки:**
  1. Авторизуватися як Supervisor — вiдкрити дашборд
  2. Авторизуватися як Coordinator — вiдкрити дашборд
  3. Авторизуватися як Admin — вiдкрити дашборд
- **Очiкуваний результат:** Всi три ролi успiшно отримують доступ до дашбордiв аналiтики
- **Прiоритет:** Високий

### TC-S-E11-S07-02: Заборона доступу для Person та Consultant
- **Передумови:** Облiковi записи з ролями Person та Consultant
- **Кроки:**
  1. Авторизуватися як Person — спробувати вiдкрити дашборд
  2. Авторизуватися як Consultant — спробувати вiдкрити дашборд
- **Очiкуваний результат:** Обидвi ролi отримують 403 Forbidden при спробi доступу
- **Прiоритет:** Високий

### TC-S-E11-S07-03: Супервiзор бачить тiльки своїх пiдопiчних
- **Передумови:** Супервiзор має 3 пiдопiчних консультантiв; у системi є 10 консультантiв загалом
- **Кроки:**
  1. Авторизуватися як Supervisor
  2. Вiдкрити дашборд метрик консультантiв
- **Очiкуваний результат:** Вiдображаються метрики тiльки 3 пiдопiчних консультантiв, а не всiх 10
- **Прiоритет:** Високий
