# Тест-кейси: S-E11-04 — Загальна аналiтика платформи — звернення та кейси

## Контекст
Ця сторi надає координатору загальну статистику платформи: кiлькiсть звернень, активних та завершених кейсiв, середня тривалiсть. Тести перевiряють коректнiсть агрегацiї з урахуванням пауз, порiвняння перiодiв та обмеження доступу.

### TC-S-E11-S04-01: Вiдображення загальної статистики
- **Передумови:** Координатор авторизований; на платформi є кейси у рiзних статусах
- **Кроки:**
  1. Перейти на дашборд загальної аналiтики
- **Очiкуваний результат:** Вiдображаються: кiлькiсть нових звернень за мiсяць, кiлькiсть активних кейсiв, кiлькiсть завершених кейсiв, середня тривалiсть кейсу
- **Прiоритет:** Високий

### TC-S-E11-S04-02: Середня тривалiсть кейсу враховує паузи
- **Передумови:** Завершений кейс тривалiстю 10 днiв, з яких 3 днi — пауза
- **Кроки:**
  1. Переглянути метрику "Середня тривалiсть кейсу"
- **Очiкуваний результат:** Тривалiсть кейсу розраховується як 7 днiв (10 - 3 днi паузи)
- **Прiоритет:** Високий

### TC-S-E11-S04-03: Порiвняння перiодiв
- **Передумови:** Координатор авторизований; є данi за два рiзнi мiсяцi
- **Кроки:**
  1. Вiдкрити дашборд загальної аналiтики
  2. Обрати перiод "Сiчень"
  3. Увiмкнути порiвняння з "Груднем"
- **Очiкуваний результат:** Поруч вiдображаються показники обох перiодiв з вiзуальним порiвнянням (зростання/спадання)
- **Прiоритет:** Середнiй

### TC-S-E11-S04-04: Заборона доступу для ролi Consultant
- **Передумови:** Користувач авторизований з роллю Consultant
- **Кроки:**
  1. Спробувати отримати доступ до API загальної аналiтики
- **Очiкуваний результат:** API повертає 403 Forbidden
- **Прiоритет:** Високий
