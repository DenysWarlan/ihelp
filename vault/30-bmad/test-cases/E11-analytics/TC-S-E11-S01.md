# Тест-кейси: S-E11-01 — Дашборд метрик консультанта для супервiзора

## Контекст
Ця сторi надає супервiзору дашборд з ключовими метриками продуктивностi консультантiв. Тести перевiряють вiдображення метрик, фiльтрацiю по перiодах, детальну картку консультанта та обмеження доступу за роллю.

### TC-S-E11-S01-01: Вiдображення дашборду з метриками консультантiв
- **Передумови:** Супервiзор авторизований; iснують консультанти з завершеними та активними кейсами
- **Кроки:**
  1. Перейти на сторiнку дашборду метрик консультантiв
  2. Переглянути список консультантiв
- **Очiкуваний результат:** Вiдображається список консультантiв з метриками: середнiй час першої вiдповiдi, середнiй час мiж повiдомленнями, кiлькiсть завершених кейсiв за мiсяць, кiлькiсть кейсiв без активностi
- **Прiоритет:** Високий

### TC-S-E11-S01-02: Фiльтрацiя метрик по перiоду
- **Передумови:** Супервiзор авторизований; є данi за декiлька мiсяцiв
- **Кроки:**
  1. Вiдкрити дашборд метрик
  2. Обрати фiльтр "Тиждень"
  3. Змiнити на "Мiсяць"
  4. Змiнити на "Квартал"
  5. Вказати довiльний дiапазон дат
- **Очiкуваний результат:** Метрики перераховуються вiдповiдно до обраного перiоду; данi коректно агрегуються для кожного дiапазону
- **Прiоритет:** Високий

### TC-S-E11-S01-03: Детальна картка консультанта
- **Передумови:** Супервiзор авторизований; на дашбордi є список консультантiв
- **Кроки:**
  1. Натиснути на iм'я консультанта у списку
- **Очiкуваний результат:** Вiдкривається детальна картка з динамiкою метрик у часi (графiки або таблицi)
- **Прiоритет:** Середнiй

### TC-S-E11-S01-04: Дашборд недоступний для ролi Person
- **Передумови:** Користувач авторизований з роллю Person
- **Кроки:**
  1. Спробувати перейти на URL дашборду метрик консультантiв
- **Очiкуваний результат:** Повертається помилка 403 Forbidden; дашборд не вiдображається
- **Прiоритет:** Високий
