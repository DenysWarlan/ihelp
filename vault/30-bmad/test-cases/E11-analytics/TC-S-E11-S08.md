# Тест-кейси: S-E11-08 — Вiзуалiзацiя трендiв метрик

## Контекст
Ця сторi вiзуалiзує тренди ключових метрик у виглядi графiкiв з можливiстю перемикання мiж перiодами. Тести перевiряють коректнiсть графiкiв динамiки кейсiв та середнього часу вiдповiдi.

### TC-S-E11-S08-01: Графiк динамiки кейсiв
- **Передумови:** Координатор авторизований; є данi за 3 мiсяцi
- **Кроки:**
  1. Вiдкрити дашборд аналiтики
  2. Переглянути графiк динамiки кейсiв
  3. Обрати вiдображення по тижнях
  4. Змiнити на вiдображення по мiсяцях
- **Очiкуваний результат:** Лiнiйний графiк коректно вiдображає динамiку нових звернень, активних та завершених кейсiв; перемикання мiж перiодами працює
- **Прiоритет:** Середнiй

### TC-S-E11-S08-02: Графiк середнього часу вiдповiдi
- **Передумови:** Є данi про час вiдповiдi консультантiв за 2 мiсяцi
- **Кроки:**
  1. Вiдкрити графiк середнього часу вiдповiдi по тижнях
- **Очiкуваний результат:** Лiнiйний графiк показує тренд середнього часу вiдповiдi консультантiв по тижнях
- **Прiоритет:** Середнiй
