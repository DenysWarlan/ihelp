# Тест-кейси: S-E09-02 — Конфiгурований лiмiт кризових кейсiв

## Контекст
Ця сторi встановлює окремий hard limit на кризовi кейси для кожного консультанта. Тести перевiряють перенаправлення при досягненнi лiмiту, жорстке блокування без виняткiв та взаємодiю кризового лiмiту iз загальним.

### TC-S-E09-S02-01: Перенаправлення кризового кейсу при досягненнi лiмiту
- **Передумови:** Консультант має 3 з 3 кризових кейсiв (лiмiт досягнутий)
- **Кроки:**
  1. Новий кризовий кейс потребує призначення
- **Очiкуваний результат:** Кризовий кейс автоматично перенаправляється на iншого консультанта з вiльними кризовими слотами
- **Прiоритет:** Високий

### TC-S-E09-S02-02: Hard limit — неможливiсть перевищити кризовий лiмiт
- **Передумови:** Консультант на кризовому лiмiтi
- **Кроки:**
  1. Спроба призначити кризовий кейс (авторозподiлом або вручну)
- **Очiкуваний результат:** Призначення заблоковано жорстко (hard limit); жодних виняткiв навiть для ручного призначення
- **Прiоритет:** Високий

### TC-S-E09-S02-03: Кризовий лiмiт як пiдмножина загального
- **Передумови:** Загальний лiмiт 10, кризовий лiмiт 3
- **Кроки:**
  1. Консультант має 3 кризових та 5 звичайних кейсiв (загалом 8)
  2. Новий кризовий кейс потребує призначення
- **Очiкуваний результат:** Кризове призначення заблоковане (лiмiт 3 вичерпаний), хоча загальний лiмiт ще не досягнутий
- **Прiоритет:** Високий
