# Тест-кейси: S-E08-04 — Автовiдповiдь людинi при кризi

## Контекст
Ця сторi реалiзує автоматичне вiдправлення контактiв екстреної лiнiї 7333 людинi при виявленнi кризового повiдомлення високого ризику. Тести перевiряють негайну доставку автовiдповiдi, паралельнiсть з ескалацiєю та обмеження тiльки для високого ризику.

### TC-S-E08-S04-01: Автоматичне вiдправлення контактiв 7333
- **Передумови:** Повiдомлення класифiковане як ВИСОКИЙ ризик
- **Кроки:**
  1. Система детектує кризове повiдомлення високого ризику
- **Очiкуваний результат:** Людина негайно отримує автовiдповiдь з номером екстреної лiнiї 7333; повiдомлення вiдправлене через канал, через який людина написала; повiдомлення маркується як системне
- **Прiоритет:** Високий

### TC-S-E08-S04-02: Автовiдповiдь не блокує ескалацiю
- **Передумови:** Кризове повiдомлення високого ризику
- **Кроки:**
  1. Система одночасно вiдправляє автовiдповiдь та запускає ескалацiю
- **Очiкуваний результат:** Автовiдповiдь та ескалацiя виконуються паралельно; затримка в одному процесi не блокує iнший
- **Прiоритет:** Високий

### TC-S-E08-S04-03: Автовiдповiдь при середньому/низькому ризику
- **Передумови:** Повiдомлення класифiковане як середнiй або низький ризик
- **Кроки:**
  1. Система детектує кризове повiдомлення середнього ризику
- **Очiкуваний результат:** Автовiдповiдь з 7333 НЕ вiдправляється (тiльки для ВИСОКОГО ризику)
- **Прiоритет:** Середнiй
