# Тест-кейси: S-E05-03 — Автогенерація посилання на відеоплатформу

## Контекст
Ця історія реалізує автоматичну генерацію посилань на відеоплатформу (Zoom з fallback на Google Meet). Тести перевіряють успішну генерацію через Zoom API, retry при rate limit, fallback на Google Meet при недоступності Zoom та ручне введення посилання при повній недоступності обох платформ.

### TC-S-E05-S03-01: Автогенерація посилання Zoom (happy path)
- **Передумови:** Zoom API доступний; консультант створює зустріч
- **Кроки:**
  1. Створити зустріч
- **Очікуваний результат:** Посилання на Zoom автоматично згенеровано та додано до зустрічі
- **Пріоритет:** Високий

### TC-S-E05-S03-02: Retry при помилці API
- **Передумови:** Zoom API повертає rate limit помилку на першу спробу
- **Кроки:**
  1. Створити зустріч
  2. Система робить retry
- **Очікуваний результат:** Після retry (до 3 спроб) посилання успішно згенеровано
- **Пріоритет:** Високий

### TC-S-E05-S03-03: Fallback на альтернативну платформу
- **Передумови:** Zoom API недоступний після 3 спроб
- **Кроки:**
  1. Створити зустріч
  2. Zoom API не відповідає тричі
- **Очікуваний результат:** Система автоматично генерує посилання через Google Meet (fallback платформа)
- **Пріоритет:** Високий

### TC-S-E05-S03-04: Обидві платформи недоступні -- ручне посилання
- **Передумови:** Zoom та Google Meet API недоступні
- **Кроки:**
  1. Створити зустріч
  2. Всі автоматичні спроби невдалі
- **Очікуваний результат:** Консультант отримує повідомлення з пропозицією створити посилання вручну; зустріч зберігається без автоматичного посилання
- **Пріоритет:** Середній
