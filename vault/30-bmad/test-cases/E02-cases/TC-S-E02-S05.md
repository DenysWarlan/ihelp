# Тест-кейси: S-E02-05 — Приватні нотатки консультанта

## Контекст
Ця історія дозволяє консультантам створювати приватні нотатки до кейсу, невидимі для Person. Тести перевіряють створення нотаток, їх недоступність для Person через API та UI, а також заборону редагування нотаток іншими консультантами.

### TC-S-E02-S05-01: Створення приватної нотатки
- **Передумови:** Консультант призначений на кейс
- **Кроки:**
  1. Консультант створює приватну нотатку до кейсу з текстом
- **Очікуваний результат:** Нотатка збережена; доступна для Staff користувачів
- **Пріоритет:** Високий

### TC-S-E02-S05-02: Person не бачить приватні нотатки
- **Передумови:** До кейсу є приватні нотатки консультанта
- **Кроки:**
  1. Person запитує дані кейсу через API
- **Очікуваний результат:** Приватні нотатки не включені у відповідь; ні через API, ні через UI
- **Пріоритет:** Високий

### TC-S-E02-S05-03: Редагування нотатки іншим консультантом
- **Передумови:** Консультант A створив нотатку; консультант B авторизований
- **Кроки:**
  1. Консультант B намагається редагувати нотатку консультанта A
- **Очікуваний результат:** Редагування заборонене; тільки автор може редагувати свою нотатку
- **Пріоритет:** Високий
