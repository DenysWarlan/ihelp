# Тест-кейси: S-E02-03 — State machine статусів кейсу

## Контекст
Ця історія реалізує state machine для управління статусами CareCase. Тести перевіряють валідні послідовні переходи статусів, заборону зворотних переходів, виняткове повернення з on_hold, автоматичне переоткриття при кризовому повідомленні та автоматичний перехід з on_hold при новому повідомленні.

### TC-S-E02-S03-01: Валідний послідовний перехід статусів
- **Передумови:** Кейс існує зі статусом "new"
- **Кроки:**
  1. Координатор призначає консультанта (new -> assigned)
  2. Консультант починає роботу (assigned -> in_progress)
  3. Планується зустріч (in_progress -> meeting_scheduled)
  4. Кейс завершується (-> completed -> closed)
- **Очікуваний результат:** Всі переходи виконуються успішно відповідно до state machine
- **Пріоритет:** Високий

### TC-S-E02-S03-02: Спроба зворотного переходу статусу
- **Передумови:** Кейс у статусі "in_progress"
- **Кроки:**
  1. Користувач намагається перевести кейс у статус "new" або "assigned"
- **Очікуваний результат:** API повертає 400 Bad Request з поясненням "Зворотний перехід заборонено"
- **Пріоритет:** Високий

### TC-S-E02-S03-03: Координатор повертає кейс з on_hold в in_progress
- **Передумови:** Кейс у статусі "on_hold"; користувач має роль Coordinator або Admin
- **Кроки:**
  1. Координатор або адмін переводить кейс з on_hold в in_progress
- **Очікуваний результат:** Перехід виконується успішно (виняток із загального правила зворотних переходів)
- **Пріоритет:** Високий

### TC-S-E02-S03-04: Автоматичне переоткриття кейсу при кризовому повідомленні
- **Передумови:** Кейс у статусі "completed"
- **Кроки:**
  1. Person надсилає кризове повідомлення до завершеного кейсу
- **Очікуваний результат:** Кейс автоматично переоткривається; активується кризовий протокол з ескалацією
- **Пріоритет:** Високий

### TC-S-E02-S03-05: Автоматичний перехід з on_hold при новому повідомленні
- **Передумови:** Кейс у статусі "on_hold"
- **Кроки:**
  1. Person надсилає нове повідомлення до кейсу
- **Очікуваний результат:** Статус автоматично змінюється на "in_progress"
- **Пріоритет:** Середній
