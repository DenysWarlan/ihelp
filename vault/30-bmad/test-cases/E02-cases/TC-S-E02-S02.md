# Тест-кейси: S-E02-02 — Зв'язок кейсу з курсом

## Контекст
Ця історія реалізує зв'язок між CareCase та курсом/уроком, з якого Person ініціював звернення. Тести перевіряють створення кейсу через кнопку "Мені важко" з прив'язкою до конкретного уроку та збереження валідності посилання при оновленні версії курсу.

### TC-S-E02-S02-01: Створення кейсу через кнопку "Мені важко" в курсі
- **Передумови:** Person проходить курс; перебуває на конкретному уроці
- **Кроки:**
  1. Person натискає кнопку "Мені важко" на сторінці уроку
  2. Заповнює анкету
- **Очікуваний результат:** Кейс створюється з заповненими sourceCourseId та sourceLessonId; консультант бачить назву курсу та уроку
- **Пріоритет:** Високий

### TC-S-E02-S02-02: Валідність посилання при оновленні версії курсу
- **Передумови:** Кейс створений з посиланням на урок; курс оновлюється до нової версії
- **Кроки:**
  1. Адмін оновлює версію курсу
  2. Консультант відкриває картку кейсу з посиланням на урок
- **Очікуваний результат:** Посилання на урок залишається валідним завдяки маппінгу old lesson ID -> new lesson ID
- **Пріоритет:** Середній
