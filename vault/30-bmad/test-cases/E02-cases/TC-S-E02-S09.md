# Тест-кейси: S-E02-09 — Форма відгуку при завершенні

## Контекст
Ця історія реалізує збір відгуків від Person після завершення кейсу. Тести перевіряють надсилання форми відгуку при переході кейсу в статус "completed", збереження рейтингу та коментаря для супервізорів, а також можливість завершення кейсу без заповнення відгуку.

### TC-S-E02-S09-01: Відправка форми відгуку при завершенні кейсу
- **Передумови:** Кейс переходить у статус "completed"
- **Кроки:**
  1. Статус кейсу змінюється на "completed"
  2. Людина отримує форму відгуку через активний канал
  3. Людина заповнює рейтинг та коментар
- **Очікуваний результат:** Відгук зберігається; доступний супервізорам для аналізу якості
- **Пріоритет:** Середній

### TC-S-E02-S09-02: Завершення кейсу без відгуку
- **Передумови:** Кейс переходить у статус "completed"; людина не заповнює відгук
- **Кроки:**
  1. Людина ігнорує форму відгуку
- **Очікуваний результат:** Кейс завершується незалежно від наявності відгуку; відгук необов'язковий
- **Пріоритет:** Середній
