# Тест-кейси: S-E03-02 — Інтеграція Telegram Bot API

## Контекст
Ця історія реалізує інтеграцію з Telegram Bot API для прийому та відправки повідомлень через Telegram. Тести перевіряють доставку повідомлень через webhook, відповіді консультанта в Telegram, підтримку вкладень та захист webhook endpoint секретним токеном.

### TC-S-E03-S02-01: Доставка повідомлення з Telegram через webhook
- **Передумови:** Telegram Bot налаштований; webhook endpoint активний; Person має зв'язаний Telegram акаунт
- **Кроки:**
  1. Person надсилає повідомлення боту в Telegram
  2. Telegram надсилає webhook на endpoint POST /webhooks/telegram
- **Очікуваний результат:** Повідомлення доставляється консультанту через платформу
- **Пріоритет:** Високий

### TC-S-E03-S02-02: Відповідь консультанта доставляється в Telegram
- **Передумови:** Person надіслав повідомлення з Telegram; консультант бачить його
- **Кроки:**
  1. Консультант пише відповідь у платформі
- **Очікуваний результат:** Відповідь доставляється людині в Telegram через Bot API
- **Пріоритет:** Високий

### TC-S-E03-S02-03: Підтримка вкладень через Telegram
- **Передумови:** Person надсилає зображення через Telegram
- **Кроки:**
  1. Person надсилає фото або документ боту в Telegram
  2. Webhook обробляє вкладення
- **Очікуваний результат:** Вкладення зберігається і відображається консультанту
- **Пріоритет:** Високий

### TC-S-E03-S02-04: Захист webhook endpoint секретним токеном
- **Передумови:** Webhook endpoint налаштований
- **Кроки:**
  1. Зовнішній запит надходить на POST /webhooks/telegram без секретного токена
- **Очікуваний результат:** Запит відхиляється; повідомлення не обробляється
- **Пріоритет:** Високий
