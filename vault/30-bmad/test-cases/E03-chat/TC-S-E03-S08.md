# Тест-кейси: S-E03-08 — Generic adapter fallback

## Контекст
Ця історія реалізує GenericAdapter як fallback для повідомлень з невизначених платформ. Тести перевіряють обробку повідомлень без platform-специфічних маркерів через generic adapter та коректне відображення таких повідомлень консультанту.

### TC-S-E03-S08-01: Обробка повідомлення через generic adapter
- **Передумови:** Повідомлення надходить з платформи, яку неможливо точно визначити
- **Кроки:**
  1. Система отримує повідомлення без platform-специфічних маркерів
  2. Factory не може визначити конкретний adapter
- **Очікуваний результат:** Повідомлення обробляється через GenericAdapter; зберігається без platform-специфічних функцій; консультант бачить позначку "generic"
- **Пріоритет:** Середній

### TC-S-E03-S08-02: Доставка повідомлення generic каналу консультанту
- **Передумови:** Повідомлення оброблене через generic adapter
- **Кроки:**
  1. Консультант переглядає переписку кейсу
- **Очікуваний результат:** Повідомлення відображається з позначкою "generic"; вміст коректний
- **Пріоритет:** Середній
