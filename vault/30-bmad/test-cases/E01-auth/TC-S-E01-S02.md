# Тест-кейси: S-E01-02 — Implicit registration та єдиний акаунт

## Контекст
Ця історія забезпечує автоматичне створення акаунту при першому OAuth-вході або відправці анкети. Тести перевіряють implicit registration, atomic upsert для запобігання дублікатів, обробку edge cases (Telegram без username, race conditions) та коректне знаходження існуючого акаунту при повторному вході.

### TC-S-E01-S02-01: Автоматичне створення акаунту при першому OAuth вході
- **Передумови:** Person не має акаунту на платформі
- **Кроки:**
  1. Person вперше входить через Google OAuth
  2. Система перевіряє наявність акаунту за email/провайдером
- **Очікуваний результат:** Автоматично створюється акаунт Person; Person отримує JWT
- **Пріоритет:** Високий

### TC-S-E01-S02-02: Створення акаунту при відправці анкети без існуючого акаунту
- **Передумови:** Person не має акаунту; заповнює анкету звернення
- **Кроки:**
  1. Person заповнює анкету з контактними даними
  2. Відправляє анкету
- **Очікуваний результат:** Акаунт створюється через atomic upsert з unique constraint на контактне поле
- **Пріоритет:** Високий

### TC-S-E01-S02-03: Telegram-користувач без username
- **Передумови:** Person має Telegram акаунт без встановленого username
- **Кроки:**
  1. Person входить через Telegram Login Widget
  2. Система отримує дані без username
- **Очікуваний результат:** Акаунт створюється за chat_id як fallback ідентифікатор
- **Пріоритет:** Середній

### TC-S-E01-S02-04: Race condition при одночасній відправці двох анкет
- **Передумови:** Person не має акаунту
- **Кроки:**
  1. Person одночасно відправляє дві анкети з однаковими контактними даними
  2. Обидва запити обробляються паралельно
- **Очікуваний результат:** Перша анкета створює акаунт; друга знаходить існуючий акаунт (без дублікатів)
- **Пріоритет:** Високий

### TC-S-E01-S02-05: Вхід через канал, використаний в анкеті
- **Передумови:** Person має акаунт, створений через анкету в Telegram
- **Кроки:**
  1. Person входить через Telegram OAuth з тим самим chat_id/контактом
- **Очікуваний результат:** Система знаходить існуючий акаунт; новий не створюється
- **Пріоритет:** Високий
