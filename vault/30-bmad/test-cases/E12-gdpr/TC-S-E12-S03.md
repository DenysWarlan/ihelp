# Тест-кейси: S-E12-03 — Право на видалення (Art.17)

## Контекст
Ця сторi реалiзує право людини на видалення персональних даних згiдно Art.17 GDPR. Тести перевiряють прийом запиту, каскадне видалення всiх типiв даних та збереження анонiмiзованої структури кейсiв для статистики.

### TC-S-E12-S03-01: Успiшний запит на видалення даних
- **Передумови:** Людина авторизована; немає кризових кейсiв
- **Кроки:**
  1. Перейти до профiлю
  2. Натиснути "Запросити видалення даних"
  3. Пiдтвердити дiю
- **Очiкуваний результат:** Запит прийнято; людина отримує пiдтвердження з орiєнтовним термiном виконання (до 30 днiв)
- **Прiоритет:** Високий

### TC-S-E12-S03-02: Каскадне видалення всiх даних
- **Передумови:** Запит на видалення прийнято; у людини є повiдомлення, нотатки, файли, прогрес курсiв
- **Кроки:**
  1. Дочекатися виконання видалення
  2. Перевiрити наявнiсть даних у БД
- **Очiкуваний результат:** Повiдомлення, нотатки, файли, прогрес курсiв, профiль — видаленi; кейси анонiмiзованi (структура зберiгається без прив'язки до особи)
- **Прiоритет:** Високий

### TC-S-E12-S03-03: Анонiмiзованi кейси зберiгають структуру для статистики
- **Передумови:** Данi людини видаленi; iснують анонiмiзованi кейси
- **Кроки:**
  1. Перевiрити анонiмiзованi кейси в БД
  2. Перевiрити дашборд аналiтики (E11)
- **Очiкуваний результат:** Кейси зберiгають структуру для метрик QC-1/QC-2; персональнi данi вiдсутнi
- **Прiоритет:** Середнiй
