# Тест-кейси: S-E12-05 — Експорт даних (Art.20 — портабельнiсть)

## Контекст
Ця сторi реалiзує право людини на портабельнiсть даних — експорт у ZIP-архiв з JSON та файлами. Тести перевiряють повноту експорту, виключення приватних нотаток консультанта, анонiмiзацiю watermark та включення активних кейсiв.

### TC-S-E12-S05-01: Успiшний експорт даних у ZIP
- **Передумови:** Людина авторизована; має профiль, iсторiю повiдомлень, прогрес курсiв, вкладенi файли
- **Кроки:**
  1. Перейти до профiлю
  2. Натиснути "Експорт моїх даних"
  3. Пiдтвердити
  4. Завантажити ZIP-архiв
- **Очiкуваний результат:** ZIP мiстить: JSON (профiль, iсторiя повiдомлень, прогрес курсiв) + вкладенi файли у вихiдному форматi
- **Прiоритет:** Високий

### TC-S-E12-S05-02: Приватнi нотатки консультанта виключенi з експорту
- **Передумови:** Консультант залишив приватнi нотатки у кейсi людини
- **Кроки:**
  1. Виконати експорт даних людини
  2. Переглянути вмiст ZIP-архiву
- **Очiкуваний результат:** Приватнi нотатки консультанта (professional notes) вiдсутнi в експортi
- **Прiоритет:** Високий

### TC-S-E12-S05-03: Watermark мiстить тiльки анонiмiзованi маркери
- **Передумови:** Людина запросила експорт
- **Кроки:**
  1. Завантажити експортований ZIP
  2. Перевiрити watermark-маркери
- **Очiкуваний результат:** Watermark мiстить тiльки Person ID + timestamp; iдентифiкатори staff вiдсутнi
- **Прiоритет:** Середнiй

### TC-S-E12-S05-04: Активнi кейси включенi в експорт
- **Передумови:** Людина має активний кейс
- **Кроки:**
  1. Запросити експорт
  2. Перевiрити вмiст експорту
- **Очiкуваний результат:** Данi активних кейсiв включенi в експорт
- **Прiоритет:** Середнiй
