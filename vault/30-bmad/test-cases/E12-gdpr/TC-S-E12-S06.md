# Тест-кейси: S-E12-06 — Взаємне блокування експорту та анонiмiзацiї

## Контекст
Ця сторi запобiгає одночасному виконанню експорту та анонiмiзацiї даних однiєї людини для забезпечення цiлiсностi. Тести перевiряють блокування анонiмiзацiї пiд час експорту та навпаки.

### TC-S-E12-S06-01: Блокування анонiмiзацiї пiд час експорту
- **Передумови:** Для людини запущено процес експорту даних
- **Кроки:**
  1. Спробувати запустити анонiмiзацiю для цiєї ж людини
- **Очiкуваний результат:** Анонiмiзацiя блокується з повiдомленням "Зачекайте завершення поточної операцiї з даними"
- **Прiоритет:** Високий

### TC-S-E12-S06-02: Блокування експорту пiд час анонiмiзацiї
- **Передумови:** Для людини запущено процес анонiмiзацiї
- **Кроки:**
  1. Спробувати запустити експорт для цiєї ж людини
- **Очiкуваний результат:** Експорт блокується з аналогiчним повiдомленням
- **Прiоритет:** Високий
