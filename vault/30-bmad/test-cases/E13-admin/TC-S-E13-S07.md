# Тест-кейси: S-E13-07 — Налаштування автоматизацiї

## Контекст
Ця сторi дозволяє адмiнiстратору змiнювати SLA-пороги, лiмiти навантаження та кризовi ключовi слова через UI з hot reload. Тести перевiряють застосування змiн без перезапуску, логування в аудит-лог та редагування кризових слiв.

### TC-S-E13-S07-01: Змiна SLA-порогiв через UI
- **Передумови:** Адмiн авторизований
- **Кроки:**
  1. Перейти до налаштувань автоматизацiї
  2. Змiнити порiг часу першої вiдповiдi з 30 хвилин на 15 хвилин
  3. Зберегти
- **Очiкуваний результат:** Змiни застосовуються без перезапуску системи (hot reload); новий порiг дiє для нових кейсiв; змiна логується в аудит-лог
- **Прiоритет:** Високий

### TC-S-E13-S07-02: Налаштування лiмiтiв навантаження
- **Передумови:** Адмiн авторизований
- **Кроки:**
  1. Змiнити максимум активних кейсiв для консультанта з 10 на 8
  2. Зберегти
- **Очiкуваний результат:** Новий лiмiт дiє; система враховує його при розподiлi кейсiв
- **Прiоритет:** Високий

### TC-S-E13-S07-03: Редагування кризових ключових слiв
- **Передумови:** Адмiн авторизований; є список кризових ключових слiв
- **Кроки:**
  1. Додати нове ключове слово до списку
  2. Видалити iснуюче ключове слово
  3. Зберегти
- **Очiкуваний результат:** Змiни застосовуються без перезапуску; кризове розпiзнавання працює з оновленим списком
- **Прiоритет:** Високий

### TC-S-E13-S07-04: Логування змiн налаштувань
- **Передумови:** Адмiн змiнив SLA-порiг
- **Кроки:**
  1. Перейти до аудит-логу
  2. Знайти запис про змiну
- **Очiкуваний результат:** Аудит-лог мiстить запис: хто змiнив, коли, старе значення -> нове значення
- **Прiоритет:** Середнiй
