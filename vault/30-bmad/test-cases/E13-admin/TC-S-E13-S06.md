# Тест-кейси: S-E13-06 — Управлiння курсами

## Контекст
Ця сторi надає адмiнiстратору CRUD для курсiв з уроками та управлiння статусами (чернетка, опублiкований, архiвний). Тести перевiряють створення курсу, змiну статусу та редагування урокiв.

### TC-S-E13-S06-01: Створення курсу з уроками
- **Передумови:** Адмiн авторизований
- **Кроки:**
  1. Перейти до управлiння курсами
  2. Натиснути "Створити курс"
  3. Ввести назву, опис
  4. Додати уроки (текст, вiдео, матерiали)
  5. Зберегти
- **Очiкуваний результат:** Курс створений у статусi "Чернетка"; уроки збереженi
- **Прiоритет:** Високий

### TC-S-E13-S06-02: Змiна статусу курсу
- **Передумови:** Iснує курс у статусi "Чернетка"
- **Кроки:**
  1. Змiнити статус на "Опублiкований"
  2. Перевiрити доступнiсть курсу для людей
  3. Змiнити статус на "Архiвний"
- **Очiкуваний результат:** Опублiкований курс доступний для людей; архiвний — прихований вiд нових, але доступний тим, хто розпочав
- **Прiоритет:** Високий

### TC-S-E13-S06-03: Редагування урокiв iснуючого курсу
- **Передумови:** Iснує опублiкований курс з уроками
- **Кроки:**
  1. Вiдкрити курс для редагування
  2. Змiнити текст уроку
  3. Зберегти
- **Очiкуваний результат:** Змiни збереженi; оновлений вмiст доступний для людей
- **Прiоритет:** Середнiй
