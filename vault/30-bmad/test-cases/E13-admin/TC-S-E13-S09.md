# Тест-кейси: S-E13-09 — Чергування кризової лiнiї

## Контекст
Ця сторi надає адмiнiстратору UI для створення графiку чергувань кризової лiнiї. Тести перевiряють створення графiку, попередження при перетинi змiн та виявлення вiдсутностi покриття.

### TC-S-E13-S09-01: Створення графiку чергувань
- **Передумови:** Адмiн авторизований; є консультанти
- **Кроки:**
  1. Перейти до налаштувань чергувань
  2. Створити графiк: понедiлок 22:00-06:00 — Консультант А
  3. Додати вiвторок 22:00-06:00 — Консультант Б
  4. Зберегти
- **Очiкуваний результат:** Графiк чергувань збережено; консультанти отримують кризовi ескалацiї вiдповiдно до графiку
- **Прiоритет:** Високий

### TC-S-E13-S09-02: Попередження при перетинi змiн
- **Передумови:** Iснує графiк чергувань на понедiлок 22:00-06:00
- **Кроки:**
  1. Спробувати призначити iншого консультанта на понедiлок 23:00-05:00
- **Очiкуваний результат:** Система попереджує про перетин змiн
- **Прiоритет:** Середнiй

### TC-S-E13-S09-03: Попередження при вiдсутностi покриття
- **Передумови:** Графiк чергувань має пробiл — середа 22:00-06:00 не призначена
- **Кроки:**
  1. Переглянути графiк чергувань
- **Очiкуваний результат:** Система вiдображає попередження про вiдсутнiсть покриття для середи
- **Прiоритет:** Середнiй
