# Тест-кейси: S-E13-01 — CRUD користувачiв та призначення ролей

## Контекст
Ця сторi надає адмiнiстратору можливiсть створювати staff-користувачiв, призначати ролi та деактивувати акаунти. Тести перевiряють створення з invite, заборону другої ролi, деактивацiю та пошук/фiльтрацiю.

### TC-S-E13-S01-01: Створення staff-користувача з роллю
- **Передумови:** Адмiн авторизований
- **Кроки:**
  1. Перейти до управлiння користувачами
  2. Натиснути "Створити користувача"
  3. Ввести email, обрати роль (наприклад, Consultant)
  4. Пiдтвердити створення
- **Очiкуваний результат:** Staff-користувач створений; надiслано invite на email; користувач з'являється у списку зi статусом "Запрошення надiслано"
- **Прiоритет:** Високий

### TC-S-E13-S01-02: Заборона призначення другої ролi
- **Передумови:** Iснує staff-користувач з роллю Consultant
- **Кроки:**
  1. Спробувати призначити цьому користувачу другу роль (наприклад, Supervisor)
- **Очiкуваний результат:** Операцiя вiдхиляється з повiдомленням "Користувач вже має роль Consultant"
- **Прiоритет:** Високий

### TC-S-E13-S01-03: Деактивацiя акаунту
- **Передумови:** Iснує активний staff-користувач без активних кейсiв
- **Кроки:**
  1. Знайти користувача у списку
  2. Натиснути "Деактивувати"
  3. Пiдтвердити дiю
- **Очiкуваний результат:** Акаунт деактивований; користувач не може увiйти в систему; данi зберiгаються (soft delete)
- **Прiоритет:** Високий

### TC-S-E13-S01-04: Пошук та фiльтрацiя списку користувачiв
- **Передумови:** В системi є користувачi з рiзними ролями та статусами
- **Кроки:**
  1. Вiдкрити список користувачiв
  2. Вiдфiльтрувати по ролi "Consultant"
  3. Вiдфiльтрувати по статусу "Деактивований"
  4. Здiйснити пошук за iменем
- **Очiкуваний результат:** Фiльтри та пошук працюють коректно; результати вiдповiдають критерiям
- **Прiоритет:** Середнiй
