# Тест-кейси: S-E13-08 — Налаштування iнтеграцiй

## Контекст
Ця сторi надає UI для налаштування зовнiшнiх iнтеграцiй (Telegram-бот) з test connection та безпечним зберiганням токенiв. Тести перевiряють успiшний та невдалий test connection та логування змiн без значень секретiв.

### TC-S-E13-S08-01: Налаштування Telegram-бота з test connection
- **Передумови:** Адмiн авторизований; є валiдний Telegram-бот токен
- **Кроки:**
  1. Перейти на сторiнку iнтеграцiй
  2. Ввести Telegram-бот токен
  3. Натиснути "Test connection"
- **Очiкуваний результат:** Вiдображається результат "Успiх" (getMe API повертає iнформацiю про бота); токен збережено у зашифрованому виглядi
- **Прiоритет:** Високий

### TC-S-E13-S08-02: Test connection з невалiдним токеном
- **Передумови:** Адмiн авторизований
- **Кроки:**
  1. Ввести невалiдний Telegram-бот токен
  2. Натиснути "Test connection"
- **Очiкуваний результат:** Вiдображається результат "Помилка" з описом проблеми; токен не зберiгається
- **Прiоритет:** Високий

### TC-S-E13-S08-03: Логування змiни токенiв без значень
- **Передумови:** Адмiн змiнив Telegram-бот токен
- **Кроки:**
  1. Переглянути аудит-лог
- **Очiкуваний результат:** Запис про змiну токену присутнiй; значення токену НЕ збережено в лозi (тiльки факт змiни)
- **Прiоритет:** Високий
