# Тест-кейси: S-E04-10 — Імпорт та експорт курсів

## Контекст
Ця історія реалізує імпорт та експорт курсів у форматі JSON bundle. Тести перевіряють імпорт валідного bundle зі створенням курсу в статусі draft, санітизацію XSS/script injection, ліміт розміру файлу 50 MB, експорт без enrollments/статистики та імпорт з існуючою назвою.

### TC-S-E04-S10-01: Імпорт валідного JSON bundle
- **Передумови:** Admin має JSON-файл з коректною структурою курсу (< 50 MB)
- **Кроки:**
  1. Перейти до "Імпорт курсу"
  2. Завантажити JSON bundle
  3. Підтвердити імпорт
- **Очікуваний результат:** Курс створено зі статусом `draft`; всі уроки та файли збережені; файли в S3
- **Пріоритет:** Високий

### TC-S-E04-S10-02: Імпорт з XSS/script injection
- **Передумови:** JSON bundle містить `<script>alert('xss')</script>` у контенті уроку
- **Кроки:**
  1. Імпортувати JSON bundle зі шкідливим контентом
- **Очікуваний результат:** HTML санітизовано: `<script>` та `on*` атрибути видалені; курс створено без шкідливого коду
- **Пріоритет:** Високий

### TC-S-E04-S10-03: Імпорт файлу понад 50 MB
- **Передумови:** JSON bundle розміром > 50 MB
- **Кроки:**
  1. Спробувати завантажити великий файл
- **Очікуваний результат:** Помилка валідації: файл перевищує допустимий розмір
- **Пріоритет:** Середній

### TC-S-E04-S10-04: Експорт курсу
- **Передумови:** Існує курс з уроками та файлами
- **Кроки:**
  1. Натиснути "Експортувати курс"
  2. Дочекатися завершення генерації
- **Очікуваний результат:** JSON bundle містить контент уроків та файли; enrollments, прогрес, статистика не включені
- **Пріоритет:** Високий

### TC-S-E04-S10-05: Імпорт курсу з існуючою назвою
- **Передумови:** Курс "Основи психологічної допомоги" вже існує; JSON bundle має таку ж назву
- **Кроки:**
  1. Імпортувати JSON bundle
- **Очікуваний результат:** Створено новий окремий курс з тією ж назвою зі статусом `draft`; існуючий курс не змінюється
- **Пріоритет:** Низький
