# Тест-кейси: S-E04-01 — Структура курсу та уроків

## Контекст
Ця історія реалізує базову структуру курсу з уроками різних типів. Тести перевіряють створення курсу з обов'язковими полями, додавання уроків різних типів (text, video, mixed), зміну порядку уроків та позначення уроку як trigger warning.

### TC-S-E04-S01-01: Створення курсу зі всіма обов'язковими полями
- **Передумови:** Admin авторизований в системі
- **Кроки:**
  1. Перейти до розділу "Курси" в адмін-панелі
  2. Натиснути "Створити курс"
  3. Заповнити поля: назва, опис, мова, теги
  4. Зберегти курс
- **Очікуваний результат:** Курс створено зі статусом `draft`; всі поля збережені коректно
- **Пріоритет:** Високий

### TC-S-E04-S01-02: Додавання уроків різних типів
- **Передумови:** Існує курс у статусі `draft`
- **Кроки:**
  1. Відкрити курс для редагування
  2. Додати урок типу text (rich text)
  3. Додати урок типу video (embed YouTube)
  4. Додати урок типу mixed (текст + відео + файл PDF)
- **Очікуваний результат:** Всі три уроки створені з відповідними типами контенту; уроки впорядковані за sortOrder
- **Пріоритет:** Високий

### TC-S-E04-S01-03: Зміна порядку уроків
- **Передумови:** Курс має 3+ уроки
- **Кроки:**
  1. Відкрити курс для редагування
  2. Перемістити третій урок на першу позицію
  3. Зберегти зміни
- **Очікуваний результат:** Порядок уроків оновлено; sortOrder перерахований
- **Пріоритет:** Середній

### TC-S-E04-S01-04: Позначення уроку як trigger warning
- **Передумови:** Курс має принаймні один урок
- **Кроки:**
  1. Відкрити урок для редагування
  2. Встановити прапорець `hasTriggerWarning`
  3. Зберегти
- **Очікуваний результат:** Урок позначений як такий, що містить чутливий контент
- **Пріоритет:** Середній
