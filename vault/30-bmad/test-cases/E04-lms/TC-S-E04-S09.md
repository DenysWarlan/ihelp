# Тест-кейси: S-E04-09 — Версіонування контенту курсів

## Контекст
Ця історія реалізує версіонування контенту курсів для забезпечення стабільного досвіду enrolled Person. Тести перевіряють, що enrolled Person бачить версію на момент enrollment, примусове оновлення всіх enrolled Person, блокування оновлення для архівних курсів та коректний перерахунок прогресу при видаленні уроку.

### TC-S-E04-S09-01: Enrolled Person бачить свою версію
- **Передумови:** Person записаний на курс (версія 1); Admin редагує курс (версія 2)
- **Кроки:**
  1. Admin змінює контент уроку в опублікованому курсі
  2. Person відкриває курс
- **Очікуваний результат:** Person бачить версію контенту на момент enrollment (версія 1)
- **Пріоритет:** Високий

### TC-S-E04-S09-02: Примусове оновлення enrolled Person
- **Передумови:** Курс має enrolled Person на старій версії
- **Кроки:**
  1. Admin натискає "Оновити всіх до нової версії"
- **Очікуваний результат:** Всі enrolled Person бачать нову версію; отримують повідомлення про зміни; маппінг old->new lesson ID коректний
- **Пріоритет:** Високий

### TC-S-E04-S09-03: Примусове оновлення заблоковано для архівного курсу
- **Передумови:** Курс у статусі `archived` (grace period)
- **Кроки:**
  1. Admin намагається примусово оновити enrolled Person
- **Очікуваний результат:** Операція заблокована; повідомлення про неможливість оновлення архівного курсу
- **Пріоритет:** Середній

### TC-S-E04-S09-04: Видалення уроку з перерахунком прогресу
- **Передумови:** Person пройшов 3 з 5 уроків; Admin видаляє 1 непройдений урок
- **Кроки:**
  1. Admin видаляє урок з опублікованого курсу
  2. Person відкриває курс
- **Очікуваний результат:** Прогрес перераховано: 3/4 (75%); видалений урок позначений як "(урок видалено у новій версії)" у кейсах
- **Пріоритет:** Середній
