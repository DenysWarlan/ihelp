# Тест-кейси: S-E17-05 — Файлове сховище (S3-compatible)

## Контекст
Ця сторія реалізує файлове сховище на базі S3-compatible сервісу (MinIO) з presigned URL для завантаження. Тести перевіряють upload/download файлів, дотримання ліміту розміру (10 МБ) та валідацію MIME types (whitelist дозволених типів).

### TC-S-E17-S05-01: Upload та download файлів
- **Передумови:** MinIO запущений; upload service налаштований
- **Кроки:**
  1. Завантажити файл розміром 5 МБ через API
  2. Отримати presigned URL для завантаження
  3. Завантажити файл за presigned URL
- **Очікуваний результат:** Файл завантажується успішно; presigned URL працює; файл завантажується без помилок
- **Пріоритет:** Високий

### TC-S-E17-S05-02: Ліміт розміру файлу
- **Передумови:** Upload service налаштований з лімітом 10 МБ
- **Кроки:**
  1. Спробувати завантажити файл розміром 11 МБ
  2. Завантажити файл розміром 10 МБ
- **Очікуваний результат:** Файл 11 МБ відхиляється з відповідною помилкою; файл 10 МБ завантажується успішно
- **Пріоритет:** Високий

### TC-S-E17-S05-03: Валідація MIME type
- **Передумови:** Whitelist дозволених MIME types налаштований
- **Кроки:**
  1. Завантажити дозволений тип файлу (JPG, PDF)
  2. Спробувати завантажити заборонений тип (EXE, BAT)
- **Очікуваний результат:** Дозволені типи завантажуються; заборонені — відхиляються з повідомленням про помилку
- **Пріоритет:** Високий
