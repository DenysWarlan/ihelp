# Тест-кейси: S-E17-03 — PostgreSQL + Prisma ORM

## Контекст
Ця сторія інтегрує PostgreSQL з Prisma ORM, включаючи initial schema, міграції та seed-скрипт. Тести перевіряють успішне застосування міграцій, створення таблиць та індексів, автоматичне застосування міграцій при старті Docker-контейнера та генерацію тестових даних через seed-скрипт.

### TC-S-E17-S03-01: Initial schema та міграції
- **Передумови:** PostgreSQL запущений; Prisma schema визначена
- **Кроки:**
  1. Запустити `prisma migrate dev`
  2. Перевірити створені таблиці: User, Role, Session
  3. Перевірити індекси на полях: careCaseId, channel, createdAt
- **Очікуваний результат:** Міграції застосовуються успішно; таблиці та індекси створені відповідно до schema
- **Пріоритет:** Високий

### TC-S-E17-S03-02: Автоматичне застосування міграцій при старті
- **Передумови:** Docker контейнер з backend та PostgreSQL
- **Кроки:**
  1. Запустити контейнер з чистою базою даних
  2. Перевірити логи запуску
  3. Перевірити стан бази даних
- **Очікуваний результат:** Міграції застосовуються автоматично при старті контейнера; таблиці створені
- **Пріоритет:** Високий

### TC-S-E17-S03-03: Seed-скрипт для dev
- **Передумови:** Чиста база даних з застосованими міграціями
- **Кроки:**
  1. Запустити seed-скрипт
  2. Перевірити наявність тестових даних
- **Очікуваний результат:** Тестові дані (користувачі, ролі) створені у базі
- **Пріоритет:** Середній
