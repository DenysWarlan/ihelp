# Sprint Plan — iHelp MVP

## Загальна iнформацiя

- **Проект:** "Є турбота" (iHelp) — Care Coordination Platform
- **Тривалiсть спринту:** 2 тижнi
- **Команда:** 1 Full-Stack розробник (Backend/Frontend), 1 DevOps/Infra (частково, спринти 1-2)
- **Загальна кiлькiсть спринтiв:** 12 (включаючи hardening)
- **Загальна тривалiсть:** ~24 тижнi (~6 мiсяцiв)
- **Загальна кiлькiсть stories:** 148

### Припущення щодо capacity

- 1 розробник = ~8-10 story points / спринт
- Кожна story оцiнюється як 1-3 SP залежно вiд складностi
- Середнє навантаження: 8-12 stories / спринт (з урахуванням рiзної складностi)
- DevOps-задачi виконуються паралельно з основною розробкою у спринтах 1-2

### Критичний шлях

```
E17 Infrastructure → E01 Auth → E02 Cases → E03 Chat → E06 Assignment → E07 SLA → E08 Crisis
```

### Залежностi мiж епiками

```
E17 Infrastructure ─┐
E16 UI Shell ───────┤
E01 Auth ───────────┼──→ E14 Public Web
                    │      ↓

                    │      ↓              ↓

```
