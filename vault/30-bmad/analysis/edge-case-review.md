# Обзор граничных случаев — платформа «Є турбота»

## Pass 1 — Первичное сканирование: 148 находок

Все 148 находок были исправлены непосредственно в исходных документах.

### PRD (prd.md): 38 находок — исправлено

Основные категории исправлений:
- **Авторизация и токены (AUTH):** отслеживание семейства refresh-токенов, CSRF-защита, верификация webhook-подписей, одноразовый invite-токен (SELECT FOR UPDATE), освобождение кризисных сессий от принудительного логаута
- **Переходы статусов кейсов (CASE):** запрещён переход «завершено → пауза», добавлены все допустимые/запрещённые переходы
- **Кризисный протокол (CRISIS):** цепочка фоллбэков SMS → push → email → phone, сканирование только сообщений Person (не заметок консультанта)
- **SLA и эскалация:** пауза SLA-таймера во время цикла отказов (rejection), rolling 24-часовое окно для лимита эскалаций
- **GDPR и приватность:** уточнение Art.20 — приватные заметки консультанта исключаются из экспорта портабельности, grace period 90 дней
- **Трансфер кейсов (TRANSFER):** включение кейсов в статусе «пауза» в список трансфера при уходе консультанта
- **Rate limiting:** учитываются только password-попытки, OAuth failures исключены

### Architecture (architecture.md): 46 находок — исправлено

Основные категории исправлений:
- **Null-safety:** guard для `message.content`, `careCase.person`, `adapter`, `consultantId`
- **Кризисная логика:** активация `isNegated()` в циклах сканирования, проверка ёмкости для всех уровней кризиса (не только critical), только upgrade уровня (Math.max)
- **Валидация трансфера:** проверка `fromConsultantId === careCase.consultantId` перед операцией
- **SLA:** обработка всех порогов (4ч/12ч/24ч) вместо раннего выхода через else-if
- **Socket.io:** повторное чтение `client.handshake.auth.token` при каждой ревалидации вместо замыкания
- **Безопасность:** привязка Docker-портов к 127.0.0.1, переменные окружения для паролей, `npm ci --omit=dev`
- **Prisma-модели:** добавлены новые enum'ы (MeetingPlatform, SlaLevel, crisis в CasePriority), family-трекинг для RefreshToken

### System Analysis (system-analysis.md): 38 находок — исправлено

Основные категории исправлений:
- **GDPR (секция 3.2):** частичный отзыв согласия, удаление во время кризиса, управление ключами шифрования, DPA
- **Безопасность (секция 3.3):** 2FA в MVP, инвалидация сессий, защита от replay-атак
- **Граничные случаи (секции 4.1–4.8):** 21+ новый edge case добавлен по всем подсекциям
- **Site Map:** доступ staff к публичным страницам, read-only для координатора, история кризисов для супервизора, OR-логика для multi-role доступа

### Business Analysis (business-analysis.md): 26 находок — исправлено

Основные категории исправлений:
- **TCO:** 5 новых статей расходов (+$9,350), итого $29,800 за 3 года
- **Организационные риски:** 5 новых рисков (единая точка отказа координатора, отток консультантов, перегрузка и др.)
- **Юридические риски:** 6 новых рисков (несовершеннолетние, GDPR-удаление при активном кейсе, keyword-алерты и др.)
- **Операционные процессы:** очередь при перегрузке, fallback при недоступности AI, подтверждение доставки уведомлений, fuzzy-matching для дедупликации, failover на Google Sheets
