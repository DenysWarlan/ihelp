# E13 -- Адмiн-панель

## Мета

Створити адмiнiстративний iнтерфейс для управлiння користувачами, курсами, налаштуваннями автоматизацiї та iнтеграцiями, з аудит-логом усiх адмiнiстративних дiй.

## Скоуп

### Входить (MVP)

- **A-1**: Управлiння користувачами -- CRUD, призначення ролей, invite-based реєстрацiя staff, деактивацiя; заборона видалення/змiни ролi останнього адмiна; одна роль на користувача; виявлення дублiкатiв акаунтiв
- **A-2**: Управлiння курсами -- делегування до E04 (CRUD курсiв/урокiв, статуси: чернетка/опублiкований/архiвний)
- **A-3**: Налаштування автоматизацiї -- SLA-пороги, лiмiти навантаження консультантiв, кризовi ключовi слова; змiна без деплою
- **A-4**: Налаштування iнтеграцiй -- Telegram-бот токен, Zoom API ключi, test connection
- Чергування кризової лiнiї -- графiк чергувань консультантiв для нiчних кризових ескалацiй
- Аудит-лог -- журнал усiх адмiнiстративних дiй з фiльтрацiєю

### Не входить

- Масове iмпортування користувачiв (CSV/Excel)
- Кастомiзацiя UI/брендування
- Управлiння email-шаблонами

## Критерiї приймання

1. Адмiн може створити staff-користувача через invite (email), призначити одну роль; invite-токен дiйсний 72 години, одноразовий
2. Система блокує видалення/деактивацiю останнього адмiна з повiдомленням
3. Система блокує видалення консультанта з активними кейсами з повiдомленням про необхiднiсть трансферу
4. Адмiн може змiнювати SLA-пороги, лiмiти навантаження та кризовi keywords через UI без перезапуску системи
5. Сторiнка iнтеграцiй дозволяє ввести токени та виконати test connection
6. Аудит-лог фiксує всi адмiн-дiї (створення/змiна/видалення) з фiльтрацiєю по користувачу, датi, типу дiї
7. Курси: адмiн може створити курс, додати уроки, змiнити статус (чернетка -> опублiкований -> архiвний)
8. Виявлення дублiкатiв: система показує потенцiйнi дублiкати акаунтiв (за email, iм'ям, Telegram ID)
