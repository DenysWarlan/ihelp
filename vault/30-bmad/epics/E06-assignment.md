# E06 — Авторозподіл звернень (Auto-Assignment Engine)

## Мета

Автоматично призначати нові CareCase відповідному консультанту за алгоритмом пріоритизації з гарантією атомарності та fallback на координатора при відсутності кандидатів.

## Scope

### Включено (MVP)

- Алгоритм розподілу: спеціалізація -> мова -> доступність -> мінімальне навантаження (ASSIGN-1)
- Atomic decrement вільних слотів з CHECK constraint (current_cases < max_cases) (ASSIGN-1)
- Fallback: кейс залишається "нове" + сповіщення координатору (ASSIGN-2)
- Координатор може перевизначити автопризначення (ASSIGN-3)
- Фільтрація консультантів за статусом: не призначати "звільняється", "деактивований", "у відпустці" (ASSIGN-6)
- Попередження координатору при ручному призначенні недоступному консультанту
- Чергування нових кейсів з SLA таймером і повідомленням Person

### Виключено

- Логування причини призначення (ASSIGN-4 — v1.1)
- Врахування timezone консультанта (ASSIGN-5 — v1.1)
- Календар доступності (ASSIGN-7 — v1.1)
- Smart Assignment (розширений алгоритм) — v1.1

## Маппінг вимог PRD

| PRD ID | Опис |
|--------|------|
| ASSIGN-1 | Автоматичний розподіл за алгоритмом з atomic decrement |
| ASSIGN-2 | Fallback на координатора при відсутності кандидатів |
| ASSIGN-3 | Координатор перевизначає автопризначення |
| ASSIGN-6 | Фільтрація за статусом консультанта |

## Критерії приймання

1. Новий кейс автоматично призначається консультанту за алгоритмом (спеціалізація -> мова -> доступність -> навантаження)
2. Race condition при одночасному призначенні останнього слота не призводить до перевищення ліміту (CHECK constraint)
3. При відсутності відповідного консультанта кейс залишається без призначення, координатор отримує сповіщення
4. Система не призначає кейси консультантам зі статусом "звільняється", "деактивований", "у відпустці"
5. Координатор може вручну призначити/перепризначити кейс з попередженням при конфлікті
6. Person отримує повідомлення про призначення консультанта або про очікування
