# E04 — LMS (Курси)

## Мета

Надати Person self-help інструмент у вигляді структурованих курсів, які доповнюють роботу з консультантом, з повним циклом управління контентом для Admin та інтеграцією з кейсами через механізм "Мені важко".

## Scope

### Включено (MVP)

- Структура курсу: Course -> Lesson (text / video / mixed) (LMS-1, LMS-2)
- Життєвий цикл курсу: draft -> published -> hidden -> archived
- Публічний каталог курсів і preview без авторизації (LMS-6)
- Enrollment з unique constraint (person + course), множинні курси одночасно
- Progress tracking: відмітка "урок пройдено", progress bar, скидання прогресу (LMS-3)
- Trigger warnings на уроках, кнопка "Мені важко" з інтеграцією в CareCase (LMS-4)
- Відображення прогресу Person в картці кейсу для консультанта (LMS-5)
- CRUD курсів і уроків в Admin-панелі, версіонування контенту (LMS-7)
- Імпорт / експорт курсів у JSON (до 50 MB)
- Валідація: мін. 1 урок для публікації, debounce "Мені важко", ліміт 3 скидання прогресу

### Виключено

- Рекомендація курсу консультантом (LMS-8 — v1.1)
- Тести / quiz після уроків (LMS-9 — v1.2)
- Сертифікат про проходження (LMS-10 — v2.0)
- SCORM-імпорт

## Маппінг вимог PRD

| PRD ID | Опис |
|--------|------|
| LMS-1 | Структура курсу: назва, опис, список уроків |
| LMS-2 | Контент уроку: rich text, video embed, файли |
| LMS-3 | Прогрес проходження: відмітка, відсоток |
| LMS-4 | Кнопка "Мені важко" -> CareCase з контекстом |
| LMS-5 | Прогрес Person видимий консультанту в картці кейсу |
| LMS-6 | Публічний каталог, preview, enrollment після авторизації |
| LMS-7 | CRUD в Admin, версіонування, маппінг old->new lesson ID |
| EDGE-40..44 | Паралельні курси, trigger, скидання, архівація з grace period |

## Критерії приймання

1. Person може переглянути каталог без авторизації та записатися на курс після входу
2. Person проходить уроки, бачить progress bar, може скинути прогрес
3. Кнопка "Мені важко" створює CareCase (або повідомлення існуючому консультанту) з контекстом курсу/уроку
4. Admin створює, редагує, публікує, приховує, архівує курси; імпортує/експортує JSON
5. Консультант бачить прогрес Person в картці кейсу
6. Архівація курсу зберігає доступ enrolled Person на 90 днів (grace period)
7. Версіонування контенту: enrolled бачать свою версію, force-update з повідомленням
