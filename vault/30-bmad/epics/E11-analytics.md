# E11 -- Контроль якостi та аналiтика

## Мета

Надати супервiзорам та координаторам дашборди з метриками ефективностi консультантiв i загальною аналiтикою платформи, щоб забезпечити контроль якостi та прийняття рiшень на основi даних.

## Скоуп

### Входить (MVP)

- **QC-1**: Метрики по кожному консультанту: середнiй час першої вiдповiдi, середнiй час мiж повiдомленнями, кiлькiсть завершених кейсiв/мiсяць, кейси без активностi
- **QC-2**: Загальна аналiтика: нових звернень/мiсяць, активних кейсiв, завершених, середня тривалiсть кейсу, зустрiчей проведено, курсiв розпочато/завершено
- Дашборд супервiзора з метриками якостi
- Дашборд координатора з операцiйними показниками

### Не входить

- QC-3: Щотижневий автозвiт (v1.1)
- QC-4: Форма вiдгуку Person (v1.1)
- QC-5: Аналiтика по темах звернень (v1.1)
- QC-6: Дашборд з bottleneck-аналiзом (v1.2)
- Зовнiшнi BI-iнструменти або експорт у Google Sheets

## Критерiї приймання

1. Супервiзор бачить дашборд з метриками кожного консультанта (час вiдповiдi, завершенi кейси, неактивнi кейси) з фiльтрацiєю по перiоду
2. Координатор бачить загальну аналiтику: кiлькiсть звернень, активних/завершених кейсiв, середню тривалiсть, статистику зустрiчей та курсiв
3. Данi оновлюються з затримкою не бiльше 15 хвилин (near real-time)
4. Дашборди доступнi тiльки для ролей Supervisor, Coordinator, Admin
5. Метрики коректно враховують паузи кейсiв та перерви консультантiв
