# E10 — Case Transfer

## Мета

Забезпечити безперервнiсть супроводу людини при тимчасовiй або постiйнiй вiдсутностi консультанта через автоматизований процес передачi кейсiв з пiдбором замiни та збереженням iсторiї.

## Scope

### Включено

- "Я йду у вiдпустку" (тимчасова передача) та "Я йду назавжди" (постiйна передача з деактивацiєю) (TRANSFER-1)
- Transfer list включає кейси в статусi "пауза"
- Перепланування зустрiчей при transfer: <24 год — скасування, >24 год — перепризначення (TRANSFER-1)
- Блокування "Я йду назавжди" при наявностi кризових кейсiв
- Автопiдбiр замiни за спецiалiзацiєю + навантаженням (TRANSFER-2)
- Повiдомлення людинi про замiну консультанта (TRANSFER-3)
- Новий консультант отримує повну iсторiю переписки та нотатки (TRANSFER-4)
- Блокування видалення/деактивацiї консультанта при активних кейсах, список блокуючих кейсiв для адмiна (TRANSFER-6)

### Виключено

- Iнiцiювання передачi координатором без запиту консультанта (TRANSFER-5 — v1.1)

## Критерiї приймання

- [ ] Консультант може iнiцiювати "Я йду у вiдпустку" або "Я йду назавжди"
- [ ] Transfer list вiдображає всi активнi кейси та кейси на паузi
- [ ] Система пропонує кандидатiв на замiну з урахуванням спецiалiзацiї та поточного навантаження
- [ ] Зустрiчi <24 год — скасовуються з повiдомленням людинi та пропозицiєю нового часу
- [ ] Зустрiчi >24 год — автоматично перепризначаються новому консультанту
- [ ] Функцiя "Я йду назавжди" заблокована при наявностi кризових кейсiв
- [ ] Людина отримує повiдомлення про замiну консультанта
- [ ] Новий консультант бачить повну iсторiю переписки та нотатки попереднього
- [ ] При постiйному вiдходi — акаунт деактивується тiльки пiсля перерозподiлу всiх кейсiв
- [ ] Адмiн не може видалити консультанта з активними кейсами; бачить список блокуючих кейсiв
