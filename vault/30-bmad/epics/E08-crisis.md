# E08 — Crisis Protocol

## Мета

Автоматично виявляти кризовi ситуацiї (суїцидальнi думки, насильство) у повiдомленнях людини та миттєво ескалювати вiдповiдальним спецiалiстам, гарантуючи 24/7 покриття.

## Scope

### Включено

- Keyword scanning вхiдних повiдомлень (текст, filename, alt-text) українською та росiйською (CRISIS-1)
- Три рiвнi ризику: високий (негайно), середнiй (1 год), низький (в порядку черги) (CRISIS-2)
- Миттєва ескалацiя при ВИСОКОМУ ризику: SMS + push координатору/супервiзору, автовiдповiдь людинi з контактами 7333, fallback chain SMS → push → email → phone call (CRISIS-3)
- Кризовий кейс вгорi всiх спискiв (CRISIS-4)
- CRUD кризових ключових слiв та шаблону автовiдповiдi для адмiна (CRISIS-5)
- Маршрутизацiя на нiчного чергового, валiдацiя графiку чергувань, fallback при вiдсутностi чергового (CRISIS-7)

### Виключено

- Лог спрацювань для аудиту (CRISIS-6 — v1.1)
- Speech-to-text для голосових повiдомлень (CRISIS-8 — v1.1)
- Мультимовнi keywords EN/AR (v1.1)

## Критерiї приймання

- [ ] Повiдомлення з кризовими словами (uk/ru) детектуються автоматично
- [ ] При ВИСОКОМУ ризику — SMS вiдправляється протягом 30 секунд
- [ ] Якщо SMS не доставлено за 2 хв — повторна спроба + fallback chain
- [ ] Людина отримує автовiдповiдь з номером 7333
- [ ] Якщо нiхто не пiдтвердив алерт за 15 хв — повторний SMS усiм супервiзорам
- [ ] Кризовий кейс вiдображається першим у всiх списках
- [ ] Нiчний черговий отримує алерт; при вiдсутностi чергового — fallback на всiх супервiзорiв
- [ ] Щоденна валiдацiя графiку чергувань: алерт при незаповнених слотах на 48 год
- [ ] Acknowledgment дозволяється без повторного MFA в рамках активної сесiї (AUTH-9)
