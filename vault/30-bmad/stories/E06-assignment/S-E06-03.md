# S-E06-03: Fallback на координатора

## Контекст
Не завжди можливо знайти відповідного консультанта автоматично — може бути відсутність вільних слотів, потрібна рідкісна спеціалізація або мова. Людина не повинна залишатися без відповіді — вона отримує підтвердження, що звернення прийнято. Координатор отримує сповіщення з причиною неможливості автопризначення для швидкого ручного вирішення.

## User Story
Як Coordinator, я хочу отримувати сповіщення коли система не знайшла підходящого консультанта, щоб вручну призначити кейс.

## Критерії приймання
- [x] AC1: Якщо не знайдено відповідного консультанта — кейс залишається зі статусом "нове"
- [x] AC2: Координатор отримує сповіщення про непризначений кейс з причиною (немає вільних, немає спеціалізації тощо)
- [x] AC3: Person отримує повідомлення: "Ваше звернення зареєстровано, з вами зв'яжуться найближчим часом"

## Технічні нотатки
- PRD: ASSIGN-2
