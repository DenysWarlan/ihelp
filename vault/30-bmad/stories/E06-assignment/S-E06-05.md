# S-E06-05: Ручне призначення та перевизначення координатором

## Контекст
Автоматичний алгоритм не може врахувати всі нюанси — іноді координатор знає, що конкретний консультант найкраще підходить для ситуації, або потрібно терміново перепризначити кейс. Попередження при призначенні недоступному консультанту або з перевищенням ліміту забезпечують усвідомлене рішення, але не блокують координатора.

## User Story
Як Coordinator, я хочу вручну призначати або перепризначати кейс консультанту, щоб обробляти нестандартні ситуації та виправляти автопризначення.

## Критерії приймання
- [x] AC1: Координатор може призначити непризначений кейс будь-якому консультанту
- [x] AC2: Координатор може перевизначити автопризначення — змінити консультанта
- [x] AC3: При призначенні недоступному консультанту (звільняється, деактивований, у відпустці) — попередження з можливістю підтвердити або скасувати
- [x] AC4: При призначенні консультанту з перевищенням ліміту навантаження — попередження
