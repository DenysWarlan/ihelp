# S-E06-01: Алгоритм автоматичного розподілу

## Контекст
Автоматичний розподіл звернень є основою масштабування платформи — без нього координатор став би вузьким місцем при зростанні кількості звернень. Пріоритизація за спеціалізацією та мовою забезпечує якість підбору, а врахування навантаження — рівномірний розподіл роботи. Алгоритм запускається автоматично при кожному новому кейсі.

## User Story
Як система, я хочу автоматично призначати нові CareCase відповідному консультанту за алгоритмом пріоритизації, щоб кожна людина отримувала найбільш підходящого консультанта без ручного втручання.

## Критерії приймання
- [x] AC1: Алгоритм розподілу застосовує критерії у порядку пріоритету: спеціалізація -> мова -> доступність -> мінімальне навантаження
- [x] AC2: Система обирає консультанта з найменшим навантаженням серед відповідних кандидатів
- [x] AC3: При наявності кількох рівнозначних кандидатів система обирає того, хто має найбільше вільних слотів
- [x] AC4: Алгоритм запускається автоматично при створенні нового CareCase
