# S-E04-03: Публічний каталог курсів та enrollment

## Контекст
Публічний каталог без авторизації знижує бар'єр для ознайомлення з курсами — людина може оцінити контент до прийняття рішення. Потік "модальне вікно згоди -> авторизація -> перший урок" має бути максимально плавним, щоб не втратити мотивацію людини. Rollback згоди при помилці OAuth захищає від ситуації, коли згода зібрана, а акаунт не створений.

## User Story
Як Person, я хочу переглядати каталог курсів без авторизації та записуватися на курс після входу, щоб обирати потрібний курс і починати навчання.

## Критерії приймання
- [ ] AC1: Каталог курсів доступний без авторизації; кожен курс має превью-сторінку (опис, список уроків, анонс)
- [ ] AC2: При натисканні "Почати курс" відображається модальне вікно згоди -> авторизація (Google/Facebook/Telegram) -> перший урок
- [ ] AC3: При помилці OAuth — rollback згоди, enrollment не створюється, повідомлення "Авторизація не вдалась"
- [ ] AC4: Запис дозволений тільки на курси зі статусом `published`; draft/hidden/archived -> "Курс недоступний"
- [ ] AC5: Спроба подвійного запису -> 409 Conflict; Person може бути записаний на кілька курсів одночасно

## Технічні нотатки

- Enrollment: unique constraint (person_id + course_id)
