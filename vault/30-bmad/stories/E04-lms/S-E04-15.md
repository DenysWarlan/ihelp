# S-E04-15: Видалення зображень з уроків

## Контекст
Admin може завантажувати зображення до уроків, але не може їх видалити. Єдиний workaround — вручну очистити текстове поле imageUrl, що не видаляє файл з MinIO і залишає orphaned файли.

## User Story
Як Admin, я хочу видаляти завантажене зображення з уроку через діалог підтвердження, щоб виправляти помилки та звільняти сховище.

## Критерії приймання
- [ ] AC1: Кнопка Remove (X icon, error color) з'являється біля поля imageUrl коли воно заповнене
- [ ] AC2: Клік відкриває confirmation modal: "Remove this image?"
- [ ] AC3: Modal показує thumbnail preview зображення
- [ ] AC4: Підтвердження очищає `lessonModel.imageUrl` та викликає `DELETE /api/storage/{key}`
- [ ] AC5: Cancel закриває modal, зображення залишається
- [ ] AC6: Якщо URL зовнішній (не MinIO) — тільки очищає поле, не викликає DELETE
- [ ] AC7: Якщо MinIO повертає 404 — ігнорувати помилку, все одно очистити поле
- [ ] AC8: Після видалення: file input скидається, toast "Image removed"
- [ ] AC9: При помилці мережі — показ помилки, imageUrl зберігається для retry
