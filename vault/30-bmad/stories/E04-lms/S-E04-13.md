# S-E04-13: Видалення курсу з модальним підтвердженням

## Контекст
Backend підтримує soft delete курсів (архівація + 90-day grace period), але у фронтенді немає кнопки та модального підтвердження. Admin не може видалити курс через UI.

## User Story
Як Admin, я хочу видаляти курси з діалогом підтвердження, щоб не видалити активний контент випадково.

## Критерії приймання
- [ ] AC1: Кнопка Delete (Trash2, danger) з'являється в header course-edit для статусів HIDDEN та DRAFT
- [ ] AC2: Кнопка Delete НЕ з'являється для PUBLISHED курсів (потрібно спочатку приховати)
- [ ] AC3: Клік відкриває confirmation modal з назвою курсу та попередженням
- [ ] AC4: Modal показує кількість enrolled студентів
- [ ] AC5: Підтвердження викликає `facade.deleteCourse(id)` і перенаправляє на список курсів
- [ ] AC6: Cancel закриває modal без побічних ефектів
- [ ] AC7: Loading state на кнопці Delete під час API виклику
- [ ] AC8: При помилці мережі — показ помилки в modal, modal не закривається

## Технічні нотатки
- PRD: LMS-10
- Створити reusable `confirm-modal` component в `libs/shared/ui/src/components/confirm-modal/`
- Backend endpoint: existing `DELETE /api/admin/courses/:id` (soft delete)
- Facade: додати метод `deleteCourse(id)`, `showDeleteModal` signal, `enrollmentsCount` signal
- Store: додати `deleteCourse` rxMethod
- Пріоритет: P1
- Оцінка: S (2-3 год)
