# S-E04-09: Версіонування контенту курсів

## Контекст
Оновлення контенту опублікованого курсу не повинно порушувати досвід enrolled Person — вони мають бачити стабільну версію. Маппінг old/new lesson ID критичний для збереження зв'язку кейсів з конкретними уроками (E02 Cases). Блокування примусового оновлення для архівних курсів під час grace period захищає людей, які завершують курс.

## User Story
Як Admin, я хочу редагувати опублікований курс із збереженням версій, щоб enrolled Person бачили стабільну версію, а нові — оновлений контент.

## Критерії приймання
- [ ] AC1: При редагуванні опублікованого курсу enrolled Person бачать версію на момент enrollment
- [ ] AC2: Admin може примусово оновити всіх enrolled до нової версії з повідомленням про зміни
- [ ] AC3: Система зберігає маппінг old lesson ID -> new lesson ID; видалені уроки позначаються як "(урок видалено у новій версії)" у кейсах
- [ ] AC4: Примусове оновлення заблоковано для архівних курсів під час grace period
- [ ] AC5: Видалення уроку з опублікованого курсу перераховує прогрес enrolled Person
