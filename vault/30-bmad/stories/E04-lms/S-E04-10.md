# S-E04-10: Імпорт та експорт курсів

## Контекст
Можливість обміну курсами між інстансами платформи критична для масштабування — організації-партнери можуть створювати контент і ділитися ним. Санітизація імпортованого контенту (XSS protection) обов'язкова, оскільки JSON bundle може містити шкідливий HTML. Асинхронна генерація великих експортів запобігає блокуванню API.

## User Story
Як Admin, я хочу імпортувати курси з JSON-файлу та експортувати існуючі, щоб обмінюватися контентом між інстансами платформи.

## Критерії приймання
- [ ] AC1: Admin може завантажити JSON bundle (до 50 MB); система валідує структуру; курс створюється зі статусом `draft`
- [ ] AC2: Файли-вкладення зберігаються в S3; підтримувані формати: PDF, MP3, MP4; максимальний розмір файлу: 10 MB
- [ ] AC3: Імпорт з XSS/script injection у контенті — санітизація HTML (видалення `<script>`, `on*` атрибутів)
- [ ] AC4: Експорт генерує JSON bundle з контентом уроків та файлами; enrollments, прогрес, статистика не експортуються
- [ ] AC5: Імпорт завжди створює новий курс, навіть якщо title збігається з існуючим

## Технічні нотатки
- Бізнес-аналіз §5.2, §5.3
- Великі експорти генеруються асинхронно (Bull queue) з повідомленням коли готово
