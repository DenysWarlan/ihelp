# S-E04-04: Проходження курсу та прогрес

## Контекст
Відстеження прогресу є важливим елементом мотивації для людини — бачити свій шлях відновлення. Progress bar має коректно працювати при будь-яких змінах структури курсу (додавання/видалення уроків). Прив'язка прогресу до lesson ID, а не до порядкового номера, забезпечує стабільність при переупорядкуванні уроків адміном.

## User Story
Як Person, я хочу проходити уроки курсу, бачити свій прогрес та відмічати уроки як пройдені, щоб відстежувати свій шлях відновлення.

## Критерії приймання
- [x] AC1: Person може відкрити урок, прочитати/переглянути контент і натиснути "Урок пройдено"
- [x] AC2: Progress bar показує `completed_lessons / total_lessons * 100%`; guard: якщо total_lessons = 0 -> progress = 0%
- [x] AC3: Після завершення всіх уроків курс позначається як пройдений
- [x] AC4: При додаванні нового уроку до опублікованого курсу прогрес автоматично перераховується; Person отримує in-app повідомлення "Додано новий урок"
- [x] AC5: Навігація між уроками (попередній/наступний) доступна на кожному уроці

## Технічні нотатки
- PRD: LMS-3
- Прогрес прив'язаний до lesson ID, не до sortOrder — зміна порядку не впливає на completed lessons
