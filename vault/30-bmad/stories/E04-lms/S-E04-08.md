# S-E04-08: Прогрес Person для консультанта

## Контекст
Контекст навчання є важливою частиною повної картини стану людини для консультанта. Знання, на якому уроці людина натиснула "Мені важко", допомагає консультанту зрозуміти тригер та адаптувати підхід. Ця інформація відображається в картці кейсу, що забезпечує єдине місце для всього контексту.

## User Story
Як Consultant, я хочу бачити прогрес Person по курсах у картці кейсу, щоб адаптувати свої рекомендації до контексту навчання.

## Критерії приймання
- [x] AC1: У картці кейсу відображаються: курси Person, progress bar по кожному, поточний урок
- [x] AC2: Видно, чи натискав Person "Мені важко" і на якому уроці
- [x] AC3: Якщо Person проходить кілька курсів одночасно — всі відображаються окремо
