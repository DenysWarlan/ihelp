# S-E04-11: CRUD курсів в Admin-панелі

## Контекст
Admin-панель є основним інструментом управління контентом LMS. Повноцінний CRUD з урахуванням впливу на enrolled Person (перерахунок прогресу, оновлення посилань у кейсах) забезпечує безпечне редагування опублікованих курсів. Soft delete зберігає дані для аналітики та аудиту.

## User Story
Як Admin, я хочу повноцінно керувати курсами та уроками через адмін-панель, щоб ефективно управляти контентом платформи.

## Критерії приймання
- [ ] AC1: Admin може створювати, переглядати, редагувати та видаляти (soft delete) курси
- [ ] AC2: Admin може створювати, редагувати, видаляти та переупорядковувати уроки в межах курсу
- [ ] AC3: Зміна порядку уроків опублікованого курсу не впливає на completed lessons enrolled Person
- [ ] AC4: Видалення уроку з опублікованого курсу перераховує прогрес та оновлює посилання в кейсах
