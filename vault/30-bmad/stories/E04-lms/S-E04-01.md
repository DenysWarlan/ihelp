# S-E04-01: Структура курсу та уроків

## Контекст
Курси самодопомоги є одним з ключових інструментів платформи для підтримки людей поза сесіями з консультантом. Гнучка структура (text, video, mixed) дозволяє створювати різноманітний контент для різних потреб. Trigger warnings на уроках — критичний елемент безпеки для людей з психологічною вразливістю.

## User Story
Як Admin, я хочу створювати курси зі структурованим контентом та додавати до них уроки різних типів, щоб Person мав доступ до якісних self-help матеріалів.

## Критерії приймання
- [ ] AC1: Admin може створити курс з полями: назва, опис, мова, теги; курс створюється зі статусом `draft`
- [ ] AC2: Admin може додавати уроки типів text (rich text), video (embed YouTube/Vimeo) та mixed (комбінація тексту, відео, файлів)
- [ ] AC3: Уроки впорядковані за sortOrder; Admin може змінювати порядок уроків
- [ ] AC4: Admin може позначати уроки з trigger warnings (`hasTriggerWarning: true`)

## Технічні нотатки
- PRD: LMS-1, LMS-2
- Файли-матеріали (PDF, MP3, MP4) зберігаються в S3 `courses/{courseId}/`
- Максимальний розмір окремого файлу: 10 MB
