# S-E04-14: Попередній перегляд курсу та уроків в адмінці

## Контекст
Admin створює та редагує курси, але не може побачити як вони виглядатимуть для студентів. Для перевірки зовнішнього вигляду доводиться публікувати курс, роблячи його видимим для всіх — ризиковано для неготового контенту.

## User Story
Як Admin, я хочу переглядати курс та окремі уроки у вигляді студента, щоб перевірити якість контенту перед публікацією.

## Критерії приймання
- [ ] AC1: Кнопка "Preview" (Eye icon) з'являється в header course-edit для всіх статусів
- [ ] AC2: Preview курсу відкривається як route `/staff/courses/:id/preview`
- [ ] AC3: Preview курсу показує student view: title, description, tags, image, lesson list
- [ ] AC4: Preview курсу НЕ має "Start Course" CTA, auth modal, lock icons — всі уроки видимі
- [ ] AC5: Top bar: синій банер "Preview Mode" з кнопкою "Back to Edit"
- [ ] AC6: Кожен рядок уроку має кнопку Preview (Eye, size 14)
- [ ] AC7: Preview уроку відкривається в modal (max-width 800px) зі student lesson view
- [ ] AC8: Preview уроку показує: title, video/YouTube embed, image, text content
- [ ] AC9: Preview уроку НЕ має sidebar navigation, complete/next buttons, progress
- [ ] AC10: Якщо `hasTriggerWarning` — показує warning banner як для студента
- [ ] AC11: Draft урок без контенту показує "No content yet"
- [ ] AC12: Invalid video URL — graceful fallback, не crash
