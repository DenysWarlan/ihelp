# S-E04-12: Скидання форм при закритті модалок

## Контекст
При закритті модалок create-course та lesson-modal форми не скидаються до початкового стану. При повторному відкритті відображаються дані попередньої взаємодії, що вводить в оману та може призвести до помилкового збереження.

## User Story
Як Admin, я хочу щоб форми скидались при закритті модалок, щоб при повторному відкритті не бачити застарілі дані.

## Критерії приймання
- [ ] AC1: Закриття lesson modal скидає `lessonModel` до defaults (title: '', content: '', contentType: 'TEXT', videoUrl: '', imageUrl: '', hasTriggerWarning: false)
- [ ] AC2: Закриття create-course modal скидає `createCourseModel` до defaults (title: '', description: '')
- [ ] AC3: File input в lesson modal скидається при закритті
- [ ] AC4: `isUploading` скидається в false при закритті
- [ ] AC5: Закриття через ESC, backdrop click та кнопку Cancel однаково скидає стан
