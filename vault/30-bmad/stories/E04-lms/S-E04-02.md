# S-E04-02: Життєвий цикл курсу

## Контекст
Керування видимістю курсів дозволяє адміну контролювати, який контент доступний аудиторії, а який ще в розробці або потребує оновлення. Архівація курсу з grace period (90 днів) гарантує, що людина зможе завершити розпочатий курс. Особлива увага — при архівації курсу, пов'язаного з активним кейсом, консультант має бути сповіщений.

## User Story
Як Admin, я хочу керувати статусами курсу (draft -> published -> hidden -> archived), щоб контролювати видимість і доступність курсів для Person.

## Критерії приймання
- [ ] AC1: Публікація курсу можлива тільки за наявності мінімум 1 уроку, заповнених назви та опису
- [ ] AC2: Published курс видимий у каталозі; hidden — невидимий, enrolled Person бачать "курс призупинено"; archived — невидимий, enrolled Person зберігають доступ протягом 90 днів (grace period)
- [ ] AC3: Admin може переводити курс між станами: draft -> published, published -> hidden, hidden -> archived, hidden -> draft, published -> draft
- [ ] AC4: При архівації курсу з active case (sourceCourseId) система сповіщує консультанта та оновлює контекст кейсу
- [ ] AC5: Enrolled Person отримують повідомлення "Курс архівовано, ви можете завершити його до [дата]"

## Технічні нотатки
- PRD: EDGE-44
- Soft delete для архівованих курсів — прогрес зберігається для аналітики
