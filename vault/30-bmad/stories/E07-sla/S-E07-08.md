# S-E07-08: Скидання SLA при автоперепризначеннi

## Контекст
Коли кейс автоматично перепризначається іншому консультанту (ескалація 24 години, S-E07-02), новий відповідальний має отримати справедливий SLA з моменту перепризначення, а не з моменту початкового звернення. Без скидання таймера новий консультант одразу потрапляє в зону порушення SLA, що несправедливо. Історія ескалацій зберігається для аналітики (E11).

## User Story
Як координатор, я хочу щоб при автоперепризначеннi кейсу (ескалацiя 24 год) SLA-таймер скидався для нового консультанта, щоб новий вiдповiдальний мав справедливий час на реакцiю.

## Критерiї приймання
- [x] AC1: При автоперепризначеннi на рiвнi 24 год — попереднi SLA job-и скасовуються
- [x] AC2: Новий SLA-таймер стартує з моменту перепризначення
- [x] AC3: Iсторiя SLA-ескалацiй зберiгається (хто був попереднiй консультант, коли вiдбулось перепризначення)

## Технiчнi нотатки
- Зберiгати SLA-iсторiю для аналiтики (E11)
