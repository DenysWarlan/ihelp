# S-E07-02: Ескалацiйнi рiвнi для нових звернень без вiдповiдi

## Контекст
Автоматична ескалація — ключовий механізм, що гарантує реакцію на кожне звернення. Чотирирівнева система (4/12/24/48 годин) забезпечує поступове залучення відповідальних осіб до розв'язання проблеми. Тісно пов'язана з S-E07-01 (старт таймера) та E06 (Auto-Assignment) для автоперепризначення на рівні 24 годин.

## User Story
Як координатор, я хочу щоб система автоматично ескалювала невiдповiдженi кейси за визначеними часовими порогами, щоб жодне звернення не залишилось без уваги.

## Критерiї приймання
- [x] AC1: >4 год без вiдповiдi — push-сповiщення консультанту
- [x] AC2: >12 год — повторний push + email консультанту
- [x] AC3: >24 год — сповiщення координатору + автоперепризначення кейсу iншому консультанту
- [x] AC4: >48 год — сповiщення адмiну
- [x] AC5: При автоперепризначеннi (24 год) SLA-таймер скидається для нового консультанта

## Технiчнi нотатки
- Кожен рiвень ескалацiї реалiзувати як окремий delayed job у Bull queue
- При вiдповiдi консультанта — скасування всiх pending ескалацiйних job-iв

## Залежностi
- E06 (Auto-Assignment) — для автоперепризначення на рiвнi 24 год
- S-E07-01 — старт SLA-таймера
- S-E07-07 — скасування ескалацiї при вiдповiдi
