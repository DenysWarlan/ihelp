# S-E07-05: Real-time дашборд SLA-статусiв для координатора

## Контекст
Координатор потребує єдиного вікна для моніторингу стану всіх активних кейсів у реальному часі. Дашборд дозволяє проактивно втручатися до спрацювання автоматичної ескалації (S-E07-02), що зменшує кількість порушень SLA. Кризові кейси (E08) мають відображатися з найвищим пріоритетом.

## User Story
Як координатор, я хочу бачити дашборд з SLA-статусами всiх активних кейсiв у реальному часi, щоб швидко iдентифiкувати проблемнi кейси та втручатись до ескалацiї.

## Критерiї приймання
- [ ] AC1: Дашборд вiдображає всi активнi кейси з поточним SLA-статусом (в нормi / попередження / порушення)
- [ ] AC2: Данi оновлюються в реальному часi (WebSocket або SSE)
- [ ] AC3: Кейси з порушенням SLA вiдображаються першими (сортування за критичнiстю)
- [ ] AC4: Для кожного кейсу видно: час очiкування, поточний рiвень ескалацiї, iм'я консультанта
- [ ] AC5: Координатор може перейти з дашборду до конкретного кейсу одним клiком

## Технiчнi нотатки
- Використовувати Socket.io для real-time оновлень
- Кольорова iндикацiя: зелений (<4 год), жовтий (4-12 год), червоний (>12 год)

## Залежностi
- S-E07-01, S-E07-03 — данi таймерiв та трекiнгу
- E08 (Crisis Protocol) — прiоритетне вiдображення кризових кейсiв
