# S-E14-08: Responsive та доступність публічних сторінок

## Контекст
Цільова аудиторія платформи iHelp часто використовує мобільні пристрої як основний спосіб доступу до інтернету. Забезпечення responsive layout та WCAG 2.1 AA доступності на всіх публічних сторінках є критичним для інклюзивності служби. Ця сторі є "cross-cutting" і покриває всі публічні екрани E14.

## User Story
Як відвідувач з мобільного пристрою, я хочу зручно переглядати всі публічні сторінки, щоб отримати допомогу незалежно від типу пристрою.

## Критерії приймання
- [ ] AC1: Всі публічні сторінки (Landing, Catalog, Preview, Request, Confirmation, Login) мають responsive layout: mobile (< 768px), tablet (768-1024px), desktop (> 1024px)
- [ ] AC2: LCP < 2 секунди на mobile (3G+)
- [ ] AC3: WCAG 2.1 AA: достатній контраст, focus states, aria labels для форм та навігації

## Технічні нотатки
- Використовує layout grid та breakpoints з E16
- Шрифт Inter завантажується як self-hosted (не CDN)
