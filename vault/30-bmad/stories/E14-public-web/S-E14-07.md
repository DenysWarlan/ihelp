# S-E14-07: Сторінка входу для Person

## Контекст
Сторінка входу забезпечує доступ зареєстрованих користувачів до особистого кабінету та курсів. Реалізує implicit registration: при першому вході через OAuth автоматично створюється акаунт (AUTH-4c), що усуває окремий крок реєстрації та спрощує onboarding.

## User Story
Як зареєстрований користувач (Person), я хочу увійти до свого акаунту через OAuth-провайдер, щоб отримати доступ до кабінету та курсів.

## Критерії приймання
- [x] AC1: Сторінка `/login` містить ілюстрацію та три OAuth-кнопки (Google / Facebook / Telegram)
- [x] AC2: Посилання на політику конфіденційності
- [x] AC3: Після успішного входу — перенаправлення до `/person` (Person Cabinet)
- [x] AC4: При першому вході через провайдер — автоматичне створення акаунту (implicit registration, AUTH-4c)

## Технічні нотатки
- Кнопка "Увійти" в навбарі веде на `/login`
