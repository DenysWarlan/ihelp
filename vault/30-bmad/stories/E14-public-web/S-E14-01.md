# S-E14-01: Landing Page

## Контекст
Головна сторінка є першою точкою контакту відвідувача з платформою iHelp. Вона має чітко пояснити місію служби та спрямувати користувача до двох основних дій: запит на допомогу або перегляд курсів. Ця сторінка визначає перше враження та конверсію нових відвідувачів (пов'язана з E16 для навбару та загального layout).

## User Story
Як відвідувач (Guest), я хочу побачити головну сторінку з описом служби та чіткими закликами до дії, щоб зрозуміти, яку допомогу я можу отримати, і обрати наступний крок.

## Критерії приймання
- [x] AC1: Сторінка `/` містить hero-секцію з описом служби, дві CTA-кнопки ("Потрібна допомога" → `/need-help`, "Переглянути курси" → `/catalog`) та блок переваг
- [x] AC2: Навбар містить: логотип, посилання "Курси", кнопку "Увійти" — відповідно до site-map
- [x] AC3: Сторінка доступна без авторизації
- [x] AC4: LCP < 2 секунди; layout responsive (mobile-first)

## Технічні нотатки
- Контент hero-секції та блоку переваг hardcoded у MVP (без CMS)
- Використовує публічний navbar з E16
