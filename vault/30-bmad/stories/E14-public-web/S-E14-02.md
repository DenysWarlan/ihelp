# S-E14-02: Каталог курсів

## Контекст
Каталог курсів дає відвідувачам можливість самостійно ознайомитися з навчальними матеріалами ще до реєстрації. Це ключовий елемент воронки залучення: побачивши релевантні курси, людина з більшою ймовірністю зареєструється або звернеться за допомогою. Каталог отримує дані з LMS API (E04) та використовує Card-компонент з E16.

## User Story
Як відвідувач, я хочу переглянути список доступних курсів із короткими описами, щоб обрати курс, який мені підходить.

## Критерії приймання
- [x] AC1: Сторінка `/catalog` відображає сітку карток курсів (назва, опис, кількість уроків)
- [x] AC2: Присутній банер "Потрібна допомога?" з посиланням на `/need-help`
- [x] AC3: Каталог доступний без авторизації
- [x] AC4: Responsive layout: сітка адаптується під mobile / tablet / desktop

## Технічні нотатки
- Дані курсів завантажуються з API (GET `/api/courses`)
- Використовує Card-компонент з E16
