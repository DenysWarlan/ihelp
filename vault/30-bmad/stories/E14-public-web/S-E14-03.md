# S-E14-03: Превью курсу

## Контекст
Сторінка превью курсу є фінальним кроком перед рішенням про реєстрацію: відвідувач може переглянути детальний опис, трейлер і структуру уроків. Контент уроків залишається заблокованим для мотивації до створення акаунту. Ця сторінка працює у зв'язці з S-E14-04 (модальне вікно авторизації).

## User Story
Як відвідувач, я хочу переглянути детальний опис курсу зі списком уроків і трейлером, щоб вирішити, чи хочу я його пройти.

## Критерії приймання
- [ ] AC1: Сторінка `/courses/:id` показує опис курсу, відео-трейлер (або анонс), список уроків (всі заблоковані для Guest)
- [ ] AC2: CTA-кнопка "Почати курс" відкриває модальне вікно авторизації
- [ ] AC3: Сторінка доступна без авторизації

## Технічні нотатки
- Список уроків отримується з API, але контент уроків недоступний без enrollment
- Відео-трейлер вбудовується через iframe або HTML5 video
