# S-E14-06: Підтвердження звернення

## Контекст
Після відправки звернення людина повинна отримати чітке підтвердження, що її запит прийнятий. Сторінка зменшує тривогу користувача, показуючи прогрес обробки та очікуваний час відповіді. Також пропонує альтернативні канали зв'язку та перегляд курсів як додаткову підтримку.

## User Story
Як людина, що відправила звернення, я хочу побачити підтвердження з очікуваним часом відповіді, щоб знати, що моє звернення отримано і буде оброблено.

## Критерії приймання
- [x] AC1: Сторінка `/need-help` (inline success view) показує іконку успіху та 3-крокову шкалу прогресу (надіслано → обробляється → консультант зв'яжеться)
- [x] AC2: Кнопка "Переглянути курси" веде на `/catalog`
- [x] AC3: Посилання на Telegram-бот для альтернативного зв'язку

## Технічні нотатки
- Очікуваний час відповіді — статичний текст у MVP (наприклад, "протягом 24 годин")
- Сторінка не вимагає авторизації
