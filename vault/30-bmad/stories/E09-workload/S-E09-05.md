# S-E09-05: Вiзуалiзацiя загального навантаження консультантiв

## Контекст
Координатору потрібен швидкий візуальний огляд навантаження всієї команди для прийняття рішень про розподіл нових кейсів та виявлення перевантажених консультантів. Progress bar з кольоровою індикацією дозволяє миттєво оцінити стан команди без необхідності переглядати кожного консультанта окремо. Окреме відображення кризових кейсів підкреслює емоційне навантаження.

## User Story
Як координатор, я хочу бачити навантаження кожного консультанта у виглядi progress bar, щоб швидко оцiнювати стан команди та приймати рiшення про розподiл.

## Критерiї приймання
- [ ] AC1: Координатор бачить список всiх консультантiв з progress bar поточне/лiмiт
- [ ] AC2: Progress bar вiдображає окремо загальнi та кризовi кейси
- [ ] AC3: Кольорова iндикацiя: зелений (<70%), жовтий (70-90%), червоний (>90% або лiмiт)
- [ ] AC4: Данi оновлюються в реальному часi

## Технiчнi нотатки
- Реалiзувати як компонент дашборду координатора
- Progress bar: основний (загальнi кейси) + внутрiшнiй (кризовi кейси)

## Залежностi
- S-E09-01 — загальнi лiмiти для вiдображення
- S-E09-02 — кризовi лiмiти для вiдображення
