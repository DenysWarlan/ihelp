# S-E17-02: Angular Frontend Scaffold

## Контекст
Frontend scaffold створює базовий Angular-проєкт з конфігурацією збірки для трьох середовищ. Proxy config для dev спрощує локальну розробку, спрямовуючи API-запити до NestJS backend. Цей scaffold є передумовою для App Shell (S-E16-01) та всіх UI-компонентів E16.

## User Story
Як розробник, я хочу ініціалізувати Angular standalone project з конфігурацією збірки, щоб мати фундамент для UI-компонентів та екранів.

## Критерії приймання
- [ ] AC1: Angular standalone project ініціалізований з routing
- [ ] AC2: Build/serve конфігурація для dev / staging / prod environments
- [ ] AC3: Proxy config для dev: `/api` -> backend (NestJS)
- [ ] AC4: Production build проходить без помилок

## Технічні нотатки
- Angular version: latest stable
- Strict mode увімкнений

## Залежності
- Немає блокуючих залежностей (базовий scaffold)
