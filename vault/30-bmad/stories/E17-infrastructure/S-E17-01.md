# S-E17-01: NestJS Backend Scaffold

## Контекст
Backend scaffold є фундаментом для всіх API-ендпоінтів платформи. Модульна архітектура NestJS дозволяє ізольовано розробляти кожен домен (auth, cases, chat, lms, users). Глобальний exception filter та ValidationPipe забезпечують консистентну обробку помилок та валідацію вхідних даних з першого дня розробки.

## User Story
Як розробник, я хочу ініціалізувати NestJS-проєкт з модульною архітектурою та базовими middleware, щоб мати фундамент для всіх API-ендпоінтів.

## Критерії приймання
- [ ] AC1: NestJS project scaffold з модульною структурою (auth, cases, chat, lms, users модулі — порожні)
- [ ] AC2: Global exception filter з уніфікованим форматом помилок (JSON)
- [ ] AC3: Request validation через class-validator (глобальний ValidationPipe)
- [ ] AC4: Health check endpoint `/health` відповідає 200 OK
- [ ] AC5: Environment validation: backend не стартує з відсутніми обов'язковими змінними

## Технічні нотатки
- `.env.example` з усіма необхідними змінними
- Config module з Joi-валідацією на старті

## Залежності
- Немає блокуючих залежностей (базовий scaffold)
