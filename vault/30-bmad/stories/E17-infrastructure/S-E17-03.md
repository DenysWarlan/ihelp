# S-E17-03: PostgreSQL + Prisma ORM

## Контекст
PostgreSQL з Prisma ORM забезпечує типізований доступ до бази даних для всіх доменних модулів. Initial schema (User, Role, Session) є основою для Auth (E01). Автоматичне застосування міграцій при старті контейнера та seed-скрипт спрощують onboarding нових розробників. Індекси на ключових полях оптимізують запити відповідно до PRD 5.4.

## User Story
Як розробник, я хочу налаштувати PostgreSQL з Prisma ORM та initial schema, щоб мати типізований доступ до бази даних.

## Критерії приймання
- [ ] AC1: Prisma schema з initial моделями: User, Role, Session
- [ ] AC2: Migrations workflow: `prisma migrate dev` / `prisma migrate deploy`
- [ ] AC3: Міграції застосовуються автоматично при старті контейнера
- [ ] AC4: Індекси на ключових полях: careCaseId, channel, createdAt (відповідно до 5.4 PRD)
- [ ] AC5: Seed-скрипт для dev-середовища (тестові дані)

## Технічні нотатки
- PostgreSQL version: 16+
- Prisma client генерується автоматично при build
