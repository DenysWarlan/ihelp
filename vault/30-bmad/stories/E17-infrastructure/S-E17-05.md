# S-E17-05: Файлове сховище (S3-compatible)

## Контекст
S3-compatible файлове сховище забезпечує єдиний інтерфейс для завантаження та зберігання файлів у чаті (S-E15-04) та курсах (E04). MinIO використовується для локальної розробки, AWS S3 -- для production, при цьому код залишається ідентичним завдяки єдиному S3 API. Presigned URLs забезпечують безпечний доступ до файлів без прямого доступу до bucket.

## User Story
Як розробник, я хочу налаштувати S3-compatible файлове сховище, щоб підтримати завантаження файлів у чаті та курсах.

## Критерії приймання
- [ ] AC1: MinIO для dev-середовища, AWS S3 для prod — єдиний інтерфейс через S3 API
- [ ] AC2: Upload service з лімітом 10 МБ на файл
- [ ] AC3: Download service з presigned URLs
- [ ] AC4: Валідація типу файлу (whitelist дозволених MIME types)

## Технічні нотатки
- `@aws-sdk/client-s3` як єдиний клієнт для MinIO і S3
- Bucket policy: приватний доступ, presigned URLs з TTL
