# S-E17-04: Redis -- Bull Queues та Socket.io Adapter

## Контекст
Redis виконує дві ключові ролі в інфраструктурі: забезпечує асинхронну обробку завдань через Bull queues (email, notifications, SLA timers) та горизонтальне масштабування WebSocket через Socket.io adapter. Підтримка 200 одночасних з'єднань відповідає вимогам PRD 5.1 для MVP.

## User Story
Як розробник, я хочу налаштувати Redis для Bull queues і Socket.io adapter, щоб забезпечити асинхронну обробку завдань і горизонтальне масштабування WebSocket.

## Критерії приймання
- [ ] AC1: Redis підключений і доступний з backend
- [ ] AC2: Bull queue налаштований для email, notifications, SLA timers
- [ ] AC3: Socket.io Redis adapter налаштований для горизонтального масштабування
- [ ] AC4: Підтримка до 200 одночасних WebSocket-з'єднань (PRD 5.1)

## Технічні нотатки
- Bull dashboard (опціонально для dev): `@bull-board/express`
- Redis version: 7+
