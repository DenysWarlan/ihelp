# S-E17-06: Docker Compose (dev stack)

## Контекст
Docker Compose об'єднує всі сервіси (postgres, redis, minio, backend, frontend) в єдиний dev-стек, що запускається однією командою. Це критично для onboarding нових розробників та консистентності середовищ. Hot-reload для backend та frontend забезпечує швидкий цикл розробки, а healthchecks гарантують коректний порядок запуску сервісів.

## User Story
Як розробник, я хочу запустити повний dev-стек однією командою, щоб швидко розгортати локальне середовище.

## Критерії приймання
- [ ] AC1: `docker compose up` піднімає: postgres, redis, minio, backend, frontend
- [ ] AC2: Час старту повного стеку < 2 хвилини
- [ ] AC3: Hot-reload для backend (NestJS) та frontend (Angular) у dev-режимі
- [ ] AC4: Volumes для збереження даних postgres та minio між перезапусками
- [ ] AC5: `.env.example` з усіма необхідними змінними та коментарями

## Технічні нотатки
- Docker Compose version: v2
- Healthchecks для postgres і redis перед стартом backend

## Залежності
- Немає блокуючих залежностей (базовий інфраструктурний компонент)
