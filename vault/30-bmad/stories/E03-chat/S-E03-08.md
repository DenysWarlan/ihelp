# S-E03-08: Generic adapter fallback

## Контекст
Платформа повинна бути стійкою до нестандартних клієнтів та невизначених джерел повідомлень. Generic adapter забезпечує, що жодне повідомлення не втрачається, навіть якщо система не може точно визначити платформу відправника. Це також підготовка до майбутнього розширення каналів (Instagram, Viber, Facebook).

## User Story
Як платформа, я хочу обробляти повідомлення з невизначених платформ через generic adapter, щоб не втрачати повідомлення при нестандартних клієнтах.

## Критерії приймання
- [ ] AC1: При неможливості визначення платформи (наприклад Telegram Web) — повідомлення обробляється через generic adapter
- [ ] AC2: Generic adapter зберігає повідомлення без platform-специфічних функцій
- [ ] AC3: Повідомлення доставляється консультанту з позначкою "generic"

## Технічні нотатки
- PRD: CHAT-15
- Adapter pattern: TelegramAdapter, WebAdapter, GenericAdapter
- GenericAdapter як fallback у factory

## Залежності
- S-E03-03: Unified Message Bus (єдина модель збереження)
- S-E03-04: Єдиний інтерфейс консультанта (відображення з позначкою "generic")
