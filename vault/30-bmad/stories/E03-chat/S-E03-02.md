# S-E03-02: Інтеграція Telegram Bot API

## Контекст
Telegram є одним з найпопулярніших месенджерів серед цільової аудиторії платформи. Інтеграція через Bot API дозволяє людям спілкуватися з консультантом у звичному середовищі без потреби відвідувати сайт. Webhook mode забезпечує миттєву доставку повідомлень і є ефективнішим за polling.

## User Story
Як людина, я хочу писати консультанту через Telegram, щоб спілкуватися у зручному для мене месенджері.

## Критерії приймання
- [x] AC1: Повідомлення з Telegram доставляється консультанту через webhook
- [x] AC2: Відповідь консультанта доставляється людині в Telegram
- [x] AC3: Підтримуються текстові повідомлення та вкладення
- [x] AC4: Webhook endpoint захищений секретним токеном

## Технічні нотатки
- PRD: CHAT-2
- Telegram Bot API webhook mode
- Endpoint: POST /webhooks/telegram
