# S-E03-06: Вкладення у повідомленнях

## Контекст
Людина може потребувати передати документи, фотографії або інші файли консультанту — наприклад, медичні документи або скріншоти. Часткове збереження (текст зберігається навіть при відхиленні завеликого файлу) є важливим для UX — людина не повинна втрачати набраний текст через технічну помилку з вкладенням.

## User Story
Як людина, я хочу надсилати зображення та документи консультанту, щоб поділитися важливими матеріалами.

## Критерії приймання
- [x] AC1: Підтримуються вкладення до 10 МБ (зображення, документи)
- [x] AC2: При перевищенні ліміту — текстова частина зберігається, вкладення відхиляється
- [x] AC3: Людина отримує повідомлення "Файл завеликий (макс 10 МБ), але ваш текст надіслано"
- [x] AC4: Вкладення зберігаються в S3/MinIO з посиланням у Message

## Технічні нотатки
- PRD: CHAT-7
- Залежність: E17 Infrastructure (S3/MinIO)
- Часткове збереження: текст OK + attachment rejected
- Валідація розміру на рівні API gateway та сервісу

## Залежності
- S-E03-03: Unified Message Bus (поле attachments у моделі Message)
- E17 Infrastructure: S3/MinIO для зберігання файлів
