# S-E03-04: Єдиний інтерфейс консультанта з індикатором каналу

## Контекст
Консультант працює з кількома кейсами одночасно, і переключення між різними месенджерами для відповідей неприйнятне з точки зору продуктивності та якості. Єдиний інтерфейс з індикатором каналу дозволяє бачити повну картину комунікації та відповідати з одного місця. Маршрутизація відповіді у правильний канал відбувається прозоро (S-E03-05).

## User Story
Як консультант, я хочу бачити всі повідомлення у єдиному інтерфейсі з позначкою каналу, щоб не перемикатися між різними платформами.

## Критерії приймання
- [x] AC1: Консультант бачить всі повідомлення кейсу в хронологічному порядку незалежно від каналу
- [x] AC2: Кожне повідомлення має іконку каналу (web / Telegram)
- [x] AC3: Консультант бачить індикатор поточного активного каналу людини
- [x] AC4: Консультант відповідає з єдиного поля — маршрутизація в канал прозора

## Технічні нотатки
- PRD: CHAT-5
- API повертає channel для кожного повідомлення
- Активний канал = канал останнього повідомлення Person

## Залежності
- S-E03-03: Unified Message Bus (єдина модель повідомлення з полем channel)
- S-E03-05: Маршрутизація відповіді (прозора доставка у канал)
