# S-E03-09: Збереження видалених та редагованих повідомлень

## Контекст
У контексті психологічної підтримки видалене або відредаговане повідомлення може містити важливу інформацію про стан людини (наприклад, суїцидальні думки, які людина потім видалила). Консультант повинен мати доступ до повної історії для якісної оцінки ситуації. Append-only історія версій також необхідна для аудиту та GDPR-відповідності.

## User Story
Як консультант, я хочу бачити оригінали видалених та редагованих повідомлень, щоб мати повну картину комунікації для якісної підтримки.

## Критерії приймання
- [ ] AC1: При видаленні повідомлення в месенджері — оригінал зберігається з позначкою "видалено відправником"
- [ ] AC2: При отриманні edited_message від Telegram — нова версія зберігається; оригінал доступний для аудиту
- [ ] AC3: Консультант бачить позначку "повідомлення відредаговано" з можливістю переглянути історію версій
- [ ] AC4: Історія версій append-only — старі версії не видаляються

## Технічні нотатки
- PRD: CHAT-16
- Модель: MessageVersion (messageId, version, content, editedAt)
- Soft delete: isDeleted flag + deletedAt timestamp
- Оригінал завжди зберігається як version 1
