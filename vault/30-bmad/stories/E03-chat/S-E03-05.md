# S-E03-05: Маршрутизація відповіді та fallback chain

## Контекст
Коректна маршрутизація відповіді забезпечує, що людина отримає повідомлення у тому каналі, де вона востаннє спілкувалась. Fallback chain є критичним для надійності — якщо Telegram бот тимчасово недоступний, повідомлення має бути доставлене альтернативним шляхом. Без fallback консультант може не знати, що повідомлення не дійшло до людини.

## User Story
Як платформа, я хочу автоматично доставляти відповідь консультанта в правильний канал, щоб людина отримала відповідь там, де вона востаннє писала.

## Критерії приймання
- [ ] AC1: Відповідь консультанта доставляється в канал останнього повідомлення Person
- [ ] AC2: Якщо Person змінила канал між повідомленнями — відповідь йде в новий канал
- [ ] AC3: Перед відправкою виконується health check каналу (перевірка bot token, доступність)
- [ ] AC4: При недоступності каналу спрацьовує fallback chain: Telegram → email → web push
- [ ] AC5: При fallback адмін отримує алерт для виправлення інтеграції

## Технічні нотатки
- PRD: CHAT-6
- Health check: ping Telegram API перед відправкою
- Fallback chain реалізується через strategy pattern
- Alert через notification service
