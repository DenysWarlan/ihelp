# S-E03-01: Веб-чат на Socket.io

## Контекст
Веб-чат є основним каналом комунікації для людей, які звертаються через сайт платформи. Real-time доставка повідомлень критична для якості підтримки — людина у вразливому стані не повинна чекати оновлення сторінки. Redis adapter забезпечує горизонтальне масштабування при зростанні навантаження.

## User Story
Як людина, я хочу надсилати повідомлення через веб-чат на сайті, щоб спілкуватися з консультантом у реальному часі.

## Критерії приймання
- [x] AC1: Person може надіслати текстове повідомлення через веб-чат; консультант отримує його в real-time
- [x] AC2: Консультант може відповісти; Person отримує відповідь у real-time
- [x] AC3: Socket.io використовує JWT для handshake (авторизація з'єднання)
- [x] AC4: Socket.io використовує Redis adapter для multi-instance scaling

## Технічні нотатки
- PRD: CHAT-1
- @nestjs/websockets + socket.io
- Redis adapter для горизонтального масштабування
- Залежність: E01 Auth (JWT)
