# S-E15-06: GDPR -- Експорт даних

## Контекст
Право на переносимість даних (Art.20 GDPR) є законодавчою вимогою. Person може запросити експорт усіх своїх даних у ZIP-архіві. Генерація виконується асинхронно через Bull queue, щоб не блокувати інтерфейс. Взаємний lock з анонімізацією запобігає конфлікту операцій.

## User Story
Як Person, я хочу запросити експорт усіх моїх даних, щоб реалізувати своє право на переносимість (Art.20 GDPR).

## Критерії приймання
- [ ] AC1: У профілі є кнопка "Експорт моїх даних"
- [ ] AC2: Експорт генерує ZIP-архів: JSON (профіль, історія повідомлень, прогрес курсів) + вкладені файли у вихідному форматі
- [ ] AC3: Активні кейси включаються в експорт
- [ ] AC4: Watermark експортованих даних містить анонімізовані маркери (Person ID + timestamp, без ідентифікаторів staff)
- [ ] AC5: Експорт та анонімізація не можуть виконуватись одночасно — взаємний lock

## Технічні нотатки
- Генерація ZIP виконується асинхронно через Bull queue (E17)
- Після готовності — сповіщення Person з посиланням на завантаження
