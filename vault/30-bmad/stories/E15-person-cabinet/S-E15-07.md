# S-E15-07: GDPR -- Видалення акаунту та відкликання згоди

## Контекст
Право на забуття (Art.17) та відкликання згоди (Art.7) є обов'язковими для GDPR-compliance. Реалізація включає 30-денний grace period, safety override для кризових кейсів та анонімізацію переписок для збереження статистики. Ця сторі тісно пов'язана з E12 (GDPR API) та кризовою логікою E02.

## User Story
Як Person, я хочу запросити видалення мого акаунту або відкликати згоду на обробку даних, щоб реалізувати свої права за GDPR (Art.17, Art.7).

## Критерії приймання
- [ ] AC1: У профілі є кнопка "Видалити акаунт" з підтвердженням
- [ ] AC2: Після запиту — 30-денний grace period; Person бачить повідомлення з датою остаточного видалення
- [ ] AC3: При відкритому кризовому кейсі — видалення відкладається з повідомленням про причину
- [ ] AC4: Можливість відкликати згоду на обробку чутливих даних (Art.9); при активному не-кризовому кейсі чутливі поля видаляються, консультант отримує сповіщення
- [ ] AC5: При кризовому кейсі — відкликання згоди відкладається (safety override)

## Технічні нотатки
- Після видалення — anonymization переписок для статистики
