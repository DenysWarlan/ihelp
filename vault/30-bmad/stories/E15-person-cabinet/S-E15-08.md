# S-E15-08: Нагадування про зустрічі

## Контекст
Нагадування є критичним для забезпечення явки Person на заплановані зустрічі з консультантом. Реалізує multi-channel fallback chain (Telegram -> email -> web push) з автоматичним переключенням при недоступності каналу. У разі повної недоступності Person сповіщуються консультант та координатор.

## User Story
Як Person, я хочу отримувати нагадування перед запланованою зустріччю, щоб не пропустити її.

## Критерії приймання
- [ ] AC1: Нагадування надходить за 1 годину та за 15 хвилин до зустрічі
- [ ] AC2: Нагадування доставляється через активний канал (Telegram / email / web push)
- [ ] AC3: При недоступності основного каналу — автоматичний fallback (Telegram -> email -> web push)
- [ ] AC4: Якщо всі канали недоступні — сповіщення консультанту та координатору

## Технічні нотатки
- Fallback chain реалізується через Bull queue з retry logic
