# S-E15-04: Обмін файлами в чаті

## Контекст
Можливість обміну файлами та зображеннями є необхідною для ефективної комунікації між Person та консультантом. Ця сторі розширює функціональність чату (S-E15-03) підтримкою drag-and-drop завантаження, preview зображень та прозорого оновлення токенів під час upload.

## User Story
Як Person, я хочу надсилати та отримувати файли і зображення в чаті, щоб ділитися матеріалами з консультантом.

## Критерії приймання
- [ ] AC1: Можливість завантажити файл або зображення у чат (drag-and-drop або кнопка)
- [ ] AC2: Ліміт розміру файлу — 10 МБ; при перевищенні — повідомлення про помилку
- [ ] AC3: Зображення відображаються як preview в чаті; інші файли — як завантажувальне посилання
- [ ] AC4: При закінченні refresh token під час завантаження — прозоре оновлення без переривання (AUTH-8a)

## Технічні нотатки
- Upload через S3-compatible API (MinIO для dev, AWS S3 для prod)

## Залежності

- S-E15-03 (Чат з консультантом)
- E01 (Auth — token refresh, AUTH-8a)
