# S-E05-03: Автогенерація посилання на відеоплатформу

## Контекст
Ручне створення посилань на Zoom/Google Meet для кожної зустрічі забирає час консультанта та збільшує ризик помилок. Автоматична генерація з retry та fallback між платформами забезпечує надійність — навіть при збоях одного сервісу зустріч не зривається. Можливість вручну вказати посилання — останній fallback.

## User Story
Як Consultant, я хочу щоб система автоматично генерувала посилання на Zoom або Google Meet, щоб не створювати посилання вручну для кожної зустрічі.

## Критерії приймання
- [ ] AC1: При створенні зустрічі система автоматично генерує посилання Zoom або Google Meet
- [ ] AC2: При помилці API (rate limit, timeout) — retry до 3 спроб через чергу
- [ ] AC3: Якщо після 3 спроб посилання не згенеровано — повідомлення консультанту з пропозицією створити вручну (fallback)
- [ ] AC4: Якщо основна платформа (Zoom) не працює — fallback на альтернативну (Google Meet) і навпаки

## Технічні нотатки
- PRD: MEET-2, EDGE-54
- Bull queue для retry генерації посилань
