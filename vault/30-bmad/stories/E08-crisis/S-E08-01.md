# S-E08-01: Сканування вхiдних повiдомлень на кризовi ключовi слова

## Контекст
Кризовий протокол починається з виявлення — система має миттєво розпізнавати ознаки кризи в повідомленнях людей. Автоматичне сканування забезпечує реагування без затримки, яка неминуча при ручному моніторингу. Підтримка української та російської мов критична для коректної роботи з цільовою аудиторією. Результат сканування передається до S-E08-02 для класифікації рівня ризику.

## User Story
Як координатор, я хочу щоб система автоматично сканувала кожне вхiдне повiдомлення на кризовi ключовi слова українською та росiйською, щоб кризовi ситуацiї виявлялись миттєво без участi людини.

## Критерiї приймання
- [ ] AC1: Кожне вхiдне повiдомлення перевiряється на збiг з конфiгурованим списком кризових слiв/фраз
- [ ] AC2: Сканування охоплює текст повiдомлення, iмена файлiв вкладень (filename) та alt-text зображень
- [ ] AC3: Пiдтримуються ключовi слова українською та росiйською мовами
- [ ] AC4: Сканування виконується синхронно при обробцi повiдомлення (до доставки консультанту)

## Технiчнi нотатки
- Використовувати case-insensitive matching з пiдтримкою кирилицi
- Конфiгурований список слiв зберiгається в БД (CRISIS-5)
