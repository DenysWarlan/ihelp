# S-E08-03: Миттєва ескалацiя при ВИСОКОМУ ризику

## Контекст
При високому ризику кожна хвилина має значення — людина може бути в небезпеці. Ескалація через out-of-band канали (SMS, email, phone) гарантує доставку навіть при forced logout або недоступності додатку. Fallback chain з автоматичним переключенням каналів забезпечує, що алерт буде отриманий відповідальною особою за будь-яких обставин.

## User Story
Як координатор, я хочу негайно отримувати SMS та push при виявленнi повiдомлення з високим ризиком, щоб кризова ситуацiя отримала реакцiю протягом хвилин.

## Критерiї приймання
- [x] AC1: При ВИСОКОМУ ризику SMS вiдправляється координатору та супервiзору протягом 30 секунд
- [x] AC2: Одночасно вiдправляється push-сповiщення
- [x] AC3: Якщо SMS не доставлено за 2 хвилини — повторна спроба + fallback chain: SMS → push → email → phone call
- [x] AC4: Кожен наступний канал у fallback chain активується пiсля timeout попереднього (30 секунд)
- [x] AC5: Якщо нiхто не пiдтвердив отримання алерту за 15 хвилин — повторний SMS усiм супервiзорам

## Технiчнi нотатки
- Ескалацiя ПОВИННА використовувати out-of-band канали (SMS, email, phone), а не тiльки in-app push
- При forced logout (AUTH-8) in-app push не доставляється — SMS/email працюють незалежно
