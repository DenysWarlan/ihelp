# S-E08-06: CRUD кризових ключових слiв та шаблону автовiдповiдi

## Контекст
Кризові патерни змінюються з часом — з'являються нові формулювання, деякі слова потребують переоцінки рівня ризику. Адміністратор повинен мати інструмент для оперативного оновлення списку без залучення розробників. Ці конфігурації безпосередньо впливають на роботу сканера (S-E08-01), класифікатора (S-E08-02) та автовідповіді (S-E08-04).

## User Story
Як адмiнiстратор, я хочу додавати, редагувати та видаляти кризовi ключовi слова та шаблон автовiдповiдi, щоб система адаптувалась до нових кризових патернiв.

## Критерiї приймання
- [ ] AC1: Адмiн може додавати новi ключовi слова/фрази з вказанням мови (uk/ru) та рiвня ризику
- [ ] AC2: Адмiн може редагувати та видаляти iснуючi ключовi слова
- [ ] AC3: Адмiн може редагувати шаблон автовiдповiдi для кризових повiдомлень
- [ ] AC4: Змiни набувають чинностi негайно (без перезапуску сервiсу)
- [ ] AC5: Система не дозволяє видалити всi ключовi слова (мiнiмум одне повинно залишатись)

## Технiчнi нотатки
- Iнтерфейс адмiна — частина E13 (Admin Panel)
- Змiни в keywords iнвалiдують кеш сканера

## Залежностi
- E13 (Admin Panel) — UI для управлiння конфiгурацiєю
- S-E08-01 — iнвалiдацiя кешу сканера при змiнах
