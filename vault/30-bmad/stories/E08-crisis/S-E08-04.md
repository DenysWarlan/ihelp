# S-E08-04: Автовiдповiдь людинi при кризi

## Контекст
Поки система ескалює алерт до відповідальних осіб (S-E08-03), людина в кризовому стані не повинна залишатися без жодної реакції. Автоматичне повідомлення з номером екстреної лінії 7333 дає людині інструмент для отримання негайної допомоги. Це критично важливий елемент безпеки, що працює паралельно з ескалацією.

## User Story
Як людина в кризовому станi, я хочу негайно отримати повiдомлення з контактами екстреної допомоги, щоб мати iнформацiю для отримання допомоги поки чекаю на консультанта.

## Критерiї приймання
- [ ] AC1: При ВИСОКОМУ ризику система автоматично вiдправляє людинi повiдомлення з номером екстреної лiнiї 7333
- [ ] AC2: Автовiдповiдь вiдправляється в канал, через який людина написала
- [ ] AC3: Шаблон автовiдповiдi конфiгурується адмiном (CRISIS-5)

## Технiчнi нотатки
- Автовiдповiдь вiдправляється паралельно з ескалацiєю (не блокує одне одного)
- Повiдомлення маркується як системне (не вiд консультанта)
