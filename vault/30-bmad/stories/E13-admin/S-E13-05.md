# S-E13-05: Виявлення дублiкатiв акаунтiв

## Контекст
Дублікати акаунтів виникають, коли людина звертається через різні канали (Telegram, web) або змінює контактні дані. Дублікати призводять до фрагментації історії допомоги та ускладнюють роботу консультантів. Автоматичне виявлення за email, ім'ям та Telegram ID при створенні нового акаунту та періодичний звіт допомагають підтримувати чистоту даних.

## User Story
Як адмiнiстратор, я хочу бачити потенцiйнi дублiкати акаунтiв, щоб пiдтримувати чистоту даних.

## Критерiї приймання
- [ ] AC1: Система показує список потенцiйних дублiкатiв при створеннi нового акаунту (за email, iм'ям, Telegram ID)
- [ ] AC2: Адмiн може переглянути деталi потенцiйних дублiкатiв та вирiшити: об'єднати або залишити окремо
- [ ] AC3: Перiодичний звiт дублiкатiв доступний у адмiн-панелi

## Технiчнi нотатки
- Пошук по точному збiгу email/Telegram ID та нечiткому збiгу iменi
- Iнтеграцiя з логiкою мержу акаунтiв (EDGE-9a)
