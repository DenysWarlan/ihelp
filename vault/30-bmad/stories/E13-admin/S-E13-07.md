# S-E13-07: Налаштування автоматизацiї

## Контекст
Параметри автоматизації (SLA-пороги, ліміти навантаження, кризові ключові слова) повинні бути доступні для зміни без перезапуску системи та без залучення розробників. Hot reload конфігурації дозволяє оперативно реагувати на змінені умови. Логування всіх змін в аудит-лог забезпечує відстежуваність та можливість відкату.

## User Story
Як адмiнiстратор, я хочу налаштовувати параметри автоматизацiї через UI без перезапуску системи, щоб гнучко реагувати на змiни потреб (A-3).

## Критерiї приймання
- [ ] AC1: Iнтерфейс налаштувань з полями: SLA-пороги (час першої вiдповiдi, час мiж повiдомленнями, ескалацiя)
- [ ] AC2: Налаштування лiмiтiв навантаження консультантiв (максимум активних кейсiв)
- [ ] AC3: Редагування списку кризових ключових слiв
- [ ] AC4: Змiни застосовуються без перезапуску системи (hot reload)
- [ ] AC5: Всi змiни налаштувань логуються в аудит-лог

## Технiчнi нотатки
- Зберiгання конфiгурацiї в БД з кешуванням та iнвалiдацiєю

## Залежностi
- E07 (SLA Monitor) — SLA-пороги
- E09 (Workload) — лiмiти навантаження
- E08 (Crisis Protocol) — кризовi ключовi слова
- S-E13-10 — аудит-лог для змiн налаштувань
