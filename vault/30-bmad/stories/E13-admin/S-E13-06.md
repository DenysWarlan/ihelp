# S-E13-06: Управлiння курсами

## Контекст
Курси є важливим інструментом самодопомоги для людей на платформі. Адміністратор потребує зручного інтерфейсу для створення та управління навчальним контентом без залучення розробників. Система статусів (чернетка, опублікований, архівний) забезпечує контрольований процес публікації, а збереження доступу до архівних курсів для тих, хто вже розпочав, запобігає втраті прогресу.

## User Story
Як адмiнiстратор, я хочу створювати, редагувати та публiкувати курси, щоб забезпечити людей навчальними матерiалами (A-2).

## Критерiї приймання
- [ ] AC1: Адмiн може створити курс: назва, опис, список урокiв (текст, вiдео, матерiали)
- [ ] AC2: Курс має статуси: чернетка, опублiкований, архiвний — з можливiстю змiни статусу
- [ ] AC3: Опублiкований курс стає доступним для людей; архiвний — прихований вiд нових, але доступний тим, хто розпочав
- [ ] AC4: Адмiн може редагувати уроки iснуючого курсу
