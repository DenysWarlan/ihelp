# S-E13-08: Налаштування iнтеграцiй

## Контекст
Зовнішні інтеграції (Telegram, Zoom) є критичними для роботи платформи — без них неможливі комунікація з людьми та проведення зустрічей. Кнопка "Test connection" дає адміністратору впевненість у коректності налаштувань до їх застосування. Шифрування токенів at rest та виключення значень з аудит-логу забезпечують безпеку облікових даних інтеграцій.

## User Story
Як адмiнiстратор, я хочу налаштовувати зовнiшнi iнтеграцiї (Telegram, Zoom), щоб пiдключити канали комунiкацiї (A-4).

## Критерiї приймання
- [ ] AC1: Сторiнка iнтеграцiй з полями: Telegram-бот токен, Zoom API ключi
- [ ] AC2: Кнопка "Test connection" для кожної iнтеграцiї з вiдображенням результату (успiх/помилка)
- [ ] AC3: Токени зберiгаються у зашифрованому виглядi
- [ ] AC4: Змiна токенiв логується в аудит-лог (без збереження значень токенiв у лозi)

## Технiчнi нотатки
- Шифрування токенiв at rest (AES-256)
- Test connection: для Telegram — getMe API, для Zoom — перевiрка валiдностi ключiв

- E05 (Video Meetings) — Zoom iнтеграцiя
