# S-E16-08: Базові UI-компоненти (частина 2 -- відображення даних)

## Контекст
Компоненти відображення даних використовуються для візуалізації кейсів, курсів, зустрічей та статистики. Badge показує статуси та пріоритети, Card є контейнером для каталогу курсів (S-E14-02) та кабінету (S-E15-01), Table -- для списків у staff-зонах, а Progress Bar відображає прогрес курсів та навантаження.

## User Story
Як розробник, я хочу створити компоненти для відображення даних (Badge, Card, Table, Progress Bar, Alert, Modal), щоб забезпечити консистентний UI.

## Критерії приймання
- [ ] AC1: Badge — варіанти для статусів кейсів та пріоритетів (кольори відповідно до design tokens)
- [ ] AC2: Card — переиспользовуваний контейнер для курсів, кейсів, зустрічей
- [ ] AC3: Table — responsive таблиця для списків (кейси, користувачі) з можливістю сортування
- [ ] AC4: Progress Bar — лінійний індикатор з відсотком (для курсів, навантаження)
- [ ] AC5: Alert Banner — варіанти: crisis (червоний), SLA warning (жовтий), info (синій)

## Технічні нотатки
- Кожен компонент — standalone Angular component
- Table на mobile — адаптується (stacked layout або горизонтальний scroll)
