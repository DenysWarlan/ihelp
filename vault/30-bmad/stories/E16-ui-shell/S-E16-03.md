# S-E16-03: Sidebar навігація (рольова)

## Контекст
Sidebar забезпечує контекстну навігацію для авторизованих користувачів різних ролей. Конфігурація пунктів меню визначається роллю з JWT token, що гарантує: Person бачить тільки свій кабінет, а Staff -- відповідні робочі інструменти. Це фундаментальний компонент для E15 (Person Cabinet) та staff-зон.

## User Story
Як розробник, я хочу реалізувати sidebar з пунктами меню відповідно до ролі користувача, щоб Person і Staff бачили тільки релевантну навігацію.

## Критерії приймання
- [ ] AC1: Person sidebar: Кабінет, Курси, Чат, Профіль
- [ ] AC2: Consultant sidebar: Мої кейси, Профіль, Вийти
- [ ] AC3: Supervisor sidebar: Всі кейси, Звіти, Кризові alerts, Вийти
- [ ] AC4: Coordinator sidebar: Dashboard, Призначення, Аналітика, Вийти
- [ ] AC5: Admin sidebar: Dashboard, Користувачі, Курси, Налаштування, Аудит, Вийти

## Технічні нотатки
- Sidebar конфігурація визначається роллю з JWT token
- Пункти меню — масив об'єктів `{ label, icon, route, roles[] }`
