# S-E16-04: Sidebar -- responsive поведінка

## Контекст
Адаптивна поведінка sidebar забезпечує зручну навігацію на всіх розмірах екрану. На desktop sidebar завжди видимий, на mobile та tablet -- collapsed для максимізації робочого простору. CSS-анімація відкриття/закриття покращує UX. Breakpoints узгоджені з загальним layout grid (S-E16-10).

## User Story
Як розробник, я хочу зробити sidebar адаптивним для різних розмірів екрану, щоб інтерфейс був зручним на всіх пристроях.

## Критерії приймання
- [ ] AC1: Desktop (> 1024px): sidebar розгорнутий збоку, завжди видимий
- [ ] AC2: Mobile (< 768px): sidebar collapsed, відкривається через hamburger-іконку
- [ ] AC3: Tablet (768-1024px): sidebar collapsed з можливістю розгорнути
- [ ] AC4: Анімація відкриття/закриття sidebar (CSS transition)

## Технічні нотатки
- Breakpoints відповідають layout grid: mobile (< 768px), tablet (768-1024px), desktop (> 1024px)
