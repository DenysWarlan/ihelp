# S-E16-09: Modal компонент

## Контекст
Modal є переиспользовуваним компонентом для діалогових вікон по всій платформі: авторизація при старті курсу (S-E14-04), підтвердження видалення акаунту (S-E15-07), підтвердження дій у staff-зонах. Реалізація focus trap та aria-атрибутів забезпечує доступність для screen readers та keyboard-навігацію.

## User Story
Як розробник, я хочу створити переиспользовуваний Modal компонент, щоб використовувати його для авторизації, підтверджень та інших діалогів.

## Критерії приймання
- [x] AC1: Modal відкривається поверх контенту з overlay (backdrop)
- [x] AC2: Закривається: кнопкою "X", кліком на overlay, клавішею Escape
- [x] AC3: Focus trap: Tab-навігація обмежена всередині модалки
- [x] AC4: Aria-атрибути: `role="dialog"`, `aria-modal="true"`, `aria-labelledby`

## Технічні нотатки
- Використовує Angular CDK Overlay або кастомна реалізація
- Підтримка передачі контенту через `ng-content` або template ref
