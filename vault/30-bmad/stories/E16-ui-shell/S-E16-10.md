# S-E16-10: Layout Grid та responsive breakpoints

## Контекст
Layout grid визначає просторову структуру всіх екранів платформи. 12-колонкова сітка з SCSS mixins для media queries забезпечує консистентний responsive дизайн без зовнішніх CSS-фреймворків. Breakpoints використовуються у всіх компонентах E16 та екранах E14/E15. WCAG 2.1 AA вимоги до контрасту валідуються як частина цієї сторі.

## User Story
Як розробник, я хочу визначити layout grid з responsive breakpoints, щоб всі екрани платформи мали консистентну сітку.

## Критерії приймання
- [ ] AC1: Breakpoints: mobile (< 768px), tablet (768-1024px), desktop (> 1024px)
- [ ] AC2: Grid-система з конфігурованою кількістю колонок (12-column grid)
- [ ] AC3: SCSS mixins для media queries: `@include mobile {}`, `@include tablet {}`, `@include desktop {}`
- [ ] AC4: WCAG 2.1 AA: мінімальний контраст 4.5:1 для тексту, 3:1 для великого тексту

## Технічні нотатки
- CSS Grid або Flexbox — без зовнішніх CSS-фреймворків (Bootstrap тощо)
- Доступність (contrast, focus states) валідується як частина PR review
