# S-E16-06: Іконки (Lucide)

## Контекст
Уніфікована бібліотека іконок забезпечує візуальну консистентність усіх компонентів. Lucide обрано за підтримку tree-shaking (у bundle потрапляють тільки використані іконки), що критично для performance. Іконки використовуються у sidebar (S-E16-03), кнопках (S-E16-07), картках (S-E16-08) та інших компонентах.

## User Story
Як розробник, я хочу підключити Lucide icon set з Angular wrapper, щоб мати уніфіковану бібліотеку іконок у всіх компонентах.

## Критерії приймання
- [ ] AC1: Lucide icons підключені як Angular module/standalone component
- [ ] AC2: Іконки підтримують параметри: size, color (використовує design tokens), stroke-width
- [ ] AC3: Tree-shaking: у bundle потрапляють тільки використані іконки

## Технічні нотатки
- Використати `lucide-angular` або обгортку над `lucide-static`
