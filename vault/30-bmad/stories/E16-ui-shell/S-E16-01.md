# S-E16-01: Angular App Shell

## Контекст
App Shell є фундаментом для всієї frontend-частини платформи. Він визначає архітектуру маршрутизації з lazy-loaded модулями для трьох зон (публічна, person cabinet, staff), що забезпечує оптимальний розмір бандлу. Route guards інтегруються з Auth (E01) для контролю доступу.

## User Story
Як розробник, я хочу створити базовий Angular standalone app із lazy-loaded route modules, щоб забезпечити каркас для всіх екранів платформи.

## Критерії приймання
- [ ] AC1: Angular standalone app ініціалізований з routing module
- [ ] AC2: Route modules lazy-loaded (публічна зона, person cabinet, staff зона)
- [ ] AC3: Є guard для авторизованих маршрутів (redirect на `/login` для неавторизованих)
- [ ] AC4: Environment configs для dev / staging / prod

## Технічні нотатки
- Конфігурація route guards інтегрується з E01 (Auth)
