# S-E16-07: Базові UI-компоненти (частина 1 -- елементи форм)

## Контекст
Компоненти форм є будівельними блоками для всіх екранів введення даних: форма звернення (S-E14-05), профіль (S-E15-05), адмін-панелі. Інтеграція з Angular Reactive Forms забезпечує декларативну валідацію, а стилі базуються на design tokens для візуальної консистентності. Button-компонент із варіантами primary/secondary/danger використовується повсюдно.

## User Story
Як розробник, я хочу створити набір компонентів форм з валідацією, щоб переиспользовувати їх у всіх екранах платформи.

## Критерії приймання
- [x] AC1: Компоненти: Text Input, Select, Checkbox, Textarea — з підтримкою Angular Reactive Forms
- [x] AC2: Кожен компонент має стани: default, hover, focus, disabled, error
- [x] AC3: Валідаційні повідомлення відображаються під полем при error-стані
- [x] AC4: Button компонент: варіанти primary, secondary, danger; стани default, hover, active, disabled, loading

## Технічні нотатки
- Компоненти — standalone Angular components
- Стилі базуються на design tokens (S-E16-05)
