# S-E16-05: Design Tokens та типографіка

## Контекст
Design tokens є єдиним джерелом правди для всіх візуальних параметрів платформи: кольори, шрифти, розміри. CSS custom properties забезпечують готовність до dark/light theme (у MVP тільки light). Шрифти Inter та Geist Mono завантажуються self-hosted для незалежності від зовнішніх CDN та покращення GDPR-compliance.

## User Story
Як розробник, я хочу задокументувати та імплементувати design tokens і типографіку, щоб всі компоненти мали консистентний вигляд.

## Критерії приймання
- [ ] AC1: CSS custom properties для всіх токенів: `--accent`, `--bg`, `--surface`, `--text`, `--error`, `--warning`, `--success` та похідні
- [ ] AC2: SCSS variables як alias для CSS custom properties
- [ ] AC3: Шрифт Inter (UI) завантажується як self-hosted (не Google Fonts CDN)
- [ ] AC4: Шрифт Geist Mono для code/data елементів
- [ ] AC5: Шкала розмірів типографіки визначена (h1-h6, body, small, caption)

## Технічні нотатки
- Джерело: Design System frame у `ihelp-design.pen`
- Dark/light theme support: CSS custom properties ready, MVP — тільки light theme

## Залежності
- Немає блокуючих залежностей (базовий компонент design system)
