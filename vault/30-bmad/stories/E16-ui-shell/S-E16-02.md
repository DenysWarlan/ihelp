# S-E16-02: Публічний Navbar

## Контекст
Публічний навбар є спільним елементом для всіх сторінок публічної зони (E14). Він адаптується залежно від стану авторизації: для Guest показує кнопку "Увійти", для авторизованого Person -- dropdown з доступом до кабінету. Навбар є ключовим елементом навігації та першим компонентом, який бачить відвідувач.

## User Story
Як розробник, я хочу реалізувати навбар для публічної зони, щоб відвідувачі мали навігацію між Landing, Курсами та входом.

## Критерії приймання
- [ ] AC1: Navbar містить: логотип (клік -> `/`), посилання "Курси" (-> `/courses`), кнопку "Увійти" (-> `/login`)
- [ ] AC2: Для авторизованого Person — кнопка "Увійти" замінюється на ім'я / аватар із dropdown (Кабінет, Вийти)
- [ ] AC3: Navbar responsive: на mobile — hamburger-меню
- [ ] AC4: Доступність: focus states, keyboard navigation, aria labels

## Технічні нотатки
- Navbar — standalone Angular component, переиспользовується у публічних сторінках
- Стан авторизації отримується з Auth service (E01)
