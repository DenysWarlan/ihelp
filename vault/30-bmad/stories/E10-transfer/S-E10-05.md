# S-E10-05: Повiдомлення людинi про замiну консультанта

## Контекст
Зміна консультанта може викликати тривогу у людини, яка довірилась конкретному спеціалісту. Прозоре повідомлення через звичний канал комунікації зменшує стрес та підтримує довіру до сервісу. Різний зміст повідомлень для тимчасової та постійної заміни допомагає людині розуміти ситуацію та налаштувати очікування.

## User Story
Як людина, яка отримує допомогу, я хочу бути повiдомленою про змiну мого консультанта, щоб я знала хто тепер вiдповiдає за мiй кейс та не вiдчувала себе покинутою.

## Критерiї приймання
- [ ] AC1: Людина отримує повiдомлення про замiну через активний канал спiлкування (Telegram, web тощо)
- [ ] AC2: Повiдомлення мiстить iм'я нового консультанта
- [ ] AC3: При тимчасовiй передачi — повiдомлення мiстить iнформацiю про тимчасовiсть замiни
- [ ] AC4: При постiйнiй передачi — повiдомлення мiстить iнформацiю про постiйну замiну

## Технiчнi нотатки
- Використовувати канал останнього повiдомлення людини (CHAT-6)
- Шаблон повiдомлення конфiгурується адмiном

- S-E10-01, S-E10-02 — тип передачi (тимчасова/постiйна)
