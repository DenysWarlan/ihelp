# S-E10-06: Передача iсторiї переписки та нотаток новому консультанту

## Контекст
Повторення своєї історії — одне з найбільш травматичних переживань для людини, яка звернулася по допомогу. Повна передача переписки та приватних нотаток дозволяє новому консультанту увійти в контекст без додаткового навантаження на людину. Історія передач забезпечує прозорість процесу та відповідальність за кожен етап.

## User Story
Як новий консультант, я хочу отримати повну iсторiю переписки та нотатки попереднього консультанта, щоб людинi не довелось повторювати свою iсторiю заново.

## Критерiї приймання
- [ ] AC1: Новий консультант бачить повну iсторiю переписки з усiх каналiв
- [ ] AC2: Новий консультант бачить приватнi нотатки попереднього консультанта
- [ ] AC3: Iсторiя передач вiдображається в кейсi (хто передав, коли, кому)
- [ ] AC4: Новий консультант отримує push-сповiщення з короткою iнформацiєю про кейс

## Технiчнi нотатки
- Данi не копiюються, а надається доступ через перепризначення кейсу

## Залежностi
- E03 (Omnichannel Chat) — iсторiя повiдомлень
- E02 (Care Cases) — CASE-4, приватнi нотатки
