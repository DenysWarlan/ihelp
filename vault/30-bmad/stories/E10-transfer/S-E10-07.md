# S-E10-07: Блокування видалення консультанта з активними кейсами

## Контекст
Видалення або деактивація консультанта з активними кейсами призведе до того, що люди залишаться без відповідального спеціаліста. Блокування на рівні API (а не тільки UI) гарантує захист від випадкового або програмного видалення. Включення кейсів у статусі "пауза" в список блокуючих запобігає втраті кейсів, що тимчасово неактивні.

## User Story
Як адмiнiстратор, я хочу щоб система не дозволяла видалити або деактивувати консультанта з активними кейсами, щоб жодна людина не залишилась без вiдповiдального консультанта.

## Критерiї приймання
- [ ] AC1: Видалення/деактивацiя консультанта заблокована при наявностi активних кейсiв
- [ ] AC2: Адмiн бачить список кейсiв, що блокують видалення
- [ ] AC3: Кожен блокуючий кейс має посилання для переходу до нього
- [ ] AC4: Пiсля перерозподiлу всiх кейсiв — видалення/деактивацiя стає доступною

## Технiчнi нотатки
- Перевiрка на рiвнi API (middleware/guard), а не тiльки UI
- Включати кейси в статусi "пауза" у список блокуючих
