# S-E10-02: Iнiцiювання постiйної передачi ("Я йду назавжди")

## Контекст
При звільненні консультанта критично забезпечити передачу всіх кейсів до деактивації акаунту. Блокування функції при наявності кризових кейсів запобігає ситуації, коли кризовий кейс залишиться в процесі передачі без відповідального. Акаунт деактивується тільки після повного перерозподілу, що гарантує безперервність супроводу.

## User Story
Як консультант, я хочу iнiцiювати постiйну передачу всiх моїх кейсiв при звiльненнi, щоб забезпечити безперервнiсть супроводу кожної людини.

## Критерiї приймання
- [ ] AC1: Консультант бачить кнопку "Я йду назавжди" в своєму профiлi
- [ ] AC2: Transfer list вiдображає всi кейси (активнi та на паузi)
- [ ] AC3: Функцiя заблокована при наявностi кризових кейсiв — консультант бачить: "Спочатку завершiть або передайте кризовi кейси"
- [ ] AC4: Акаунт деактивується ТIЛЬКИ пiсля перерозподiлу всiх кейсiв

## Технiчнi нотатки
- Деактивацiя акаунту — фiнальний крок пiсля пiдтвердження перерозподiлу
