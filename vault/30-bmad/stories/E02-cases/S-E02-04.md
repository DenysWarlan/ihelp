# S-E02-04: Призначення консультанта

## Контекст
Призначення консультанта на кейс — це ключовий момент, який визначає швидкість та якість допомоги. Ця історія реалізує інтерфейс ручного призначення координатором, тоді як алгоритм автоматичного розподілу реалізується в E06 Assignment Engine. Audit log призначень необхідний для контролю якості та розслідування інцидентів.

## User Story
Як координатор, я хочу призначити консультанта на кейс вручну або дозволити системі зробити це автоматично, щоб кожна людина швидко отримала відповідного спеціаліста.

## Критерії приймання
- [ ] AC1: Координатор може вручну призначити консультанта на кейс
- [ ] AC2: API endpoint POST /cases/:id/assign приймає consultantId
- [ ] AC3: При призначенні статус кейсу змінюється на "assigned"
- [ ] AC4: Призначення логується в audit log (хто, кого, коли)

## Технічні нотатки
- PRD: CASE-3
- Алгоритм авторозподілу — в scope E06 Assignment Engine
- Цей epic реалізує тільки інтерфейс призначення

## Залежності
- S-E02-03: State machine (перехід в статус "assigned")
- S-E02-06: Audit log (логування призначення)
- E06 Assignment: алгоритм авторозподілу
