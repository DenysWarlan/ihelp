# S-E02-02: Зв'язок кейсу з курсом

## Контекст
Людина, яка проходить курс самодопомоги, може зіткнутися з тригерним контентом і потребувати підтримки консультанта. Передача контексту уроку в кейс дозволяє консультанту зрозуміти ситуацію без зайвих запитань, що критично для людини у вразливому стані. Ця історія є точкою інтеграції між E02 Cases та E04 LMS.

## User Story
Як людина, що проходить курс, я хочу натиснути кнопку "Мені важко" і створити звернення з контекстом уроку, щоб консультант розумів мою ситуацію без повторних пояснень.

## Критерії приймання
- [ ] AC1: Кейс, створений через кнопку в курсі, містить sourceCourseId та sourceLessonId
- [ ] AC2: Консультант бачить назву курсу та уроку в картці кейсу
- [ ] AC3: Посилання на урок залишається валідним навіть при оновленні версії курсу

## Технічні нотатки
- PRD: CASE-6
- Зв'язок через поля sourceCourseId, sourceLessonId в моделі CareCase
- Маппінг old lesson ID → new lesson ID при версіонуванні (див. LMS-7)

## Залежності

- E04 LMS: S-E04-06 (кнопка "Мені важко")
- E04 LMS: S-E04-09 (версіонування контенту — маппінг lesson ID)
