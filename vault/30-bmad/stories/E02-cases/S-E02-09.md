# S-E02-09: Форма відгуку при завершенні

## Контекст
Зворотний зв'язок від підопічних є основним інструментом оцінки якості роботи консультантів та платформи загалом. Важливо, що відгук необов'язковий — людина не повинна відчувати тиск після завершення кейсу. Зібрані дані використовуються супервізорами для аналізу якості та покращення процесів (E11 Analytics).

## User Story
Як людина, я хочу залишити відгук після завершення кейсу, щоб допомогти покращити якість підтримки.

## Критерії приймання
- [ ] AC1: При переході кейсу в статус "completed" людина отримує коротку форму відгуку
- [ ] AC2: Форма надсилається через активний канал комунікації
- [ ] AC3: Відгук зберігається і доступний супервізорам для аналізу якості
- [ ] AC4: Відгук необов'язковий — кейс завершується незалежно від наявності відгуку

## Технічні нотатки
- PRD: CASE-8 (v1.1)
- Модель: CaseFeedback (caseId, rating, comment, createdAt)

## Залежності
- S-E02-03: State machine (тригер на статус "completed")
- E03 Chat: канал доставки форми відгуку
- E11 Analytics: використання даних відгуків
