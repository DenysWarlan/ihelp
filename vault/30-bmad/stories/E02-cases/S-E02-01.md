# S-E02-01: Створення кейсу з анкети

## Контекст
Створення кейсу — це перший крок взаємодії людини з системою підтримки. Анкета збирає мінімально необхідну інформацію для маршрутизації звернення до відповідного консультанта. Обмеження одного активного кейсу на Person запобігає фрагментації допомоги та забезпечує цілісний підхід до кожної ситуації.

## User Story
Як людина, я хочу створити звернення через анкету на сайті або в Telegram-боті, щоб отримати допомогу від консультанта.

## Критерії приймання
- [x] AC1: Анкета містить поля: ім'я, країна, мова, тема, терміновість
- [x] AC2: Кейс створюється тільки при наявності GDPR-згоди (dataConsentAt NOT NULL)
- [x] AC3: Partial unique index гарантує один активний кейс на Person — при спробі створити другий повертається помилка з поясненням
- [x] AC4: Кейс отримує початковий статус "new"

## Технічні нотатки
- PRD: CASE-1
- Залежність від E01 Auth (GDPR consent)
- Unique partial index: WHERE status NOT IN ('completed', 'closed')

## Залежності
- E01 Auth: S-E01-07 (GDPR-згода обов'язкова для створення кейсу)
- E01 Auth: S-E01-02 (implicit registration при першій анкеті)
