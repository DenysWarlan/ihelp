# S-E11-03: Метрика кейсiв без активностi

## Контекст
Занедбані кейси — це люди, які не отримують допомоги. Автоматичне виявлення кейсів без активності дозволяє супервізору вчасно втрутитися та з'ясувати причину (перевантаження консультанта, забутий кейс, технічна проблема). Поріг неактивності є конфігурованим через адмін-панель (E13) для адаптації до різних типів супроводу.

## User Story
Як супервiзор, я хочу бачити перелiк кейсiв без активностi по кожному консультанту, щоб вчасно реагувати на занедбанi кейси.

## Критерiї приймання
- [ ] AC1: Система визначає кейси без активностi (без повiдомлень вiд консультанта протягом заданого порогу)
- [ ] AC2: Список неактивних кейсiв вiдображається з вказiвкою тривалостi простою та iм'я консультанта
- [ ] AC3: Порiг неактивностi налаштовується через E13 Admin (за замовчуванням 7 днiв)

## Технiчнi нотатки
- Перерви консультантiв (вiдпустка, лiкарняний) мають виключатися з розрахунку

## Залежностi
- E07 (SLA Monitor) — пороговi значення
- E09 (Workload) — статуси консультантiв (вiдпустка, лiкарняний)
- E13 (Admin Panel) — конфiгурацiя порогу неактивностi
