# S-E11-08: Вiзуалiзацiя трендiв метрик

## Контекст
Числові показники за один період не дають повної картини — тренди дозволяють бачити напрямок змін та прогнозувати навантаження. Графіки динаміки звернень, кейсів та часу відповіді по тижнях/місяцях допомагають координатору виявляти сезонні патерни, оцінювати ефект організаційних змін та планувати ресурси на майбутнє.

## User Story
Як координатор, я хочу бачити графiки динамiки ключових показникiв у часi, щоб вiдстежувати тренди та прогнозувати навантаження.

## Критерiї приймання
- [ ] AC1: Графiки вiдображають динамiку нових звернень, активних кейсiв, завершених кейсiв по тижнях/мiсяцях
- [ ] AC2: Графiк середнього часу вiдповiдi консультантiв по тижнях
- [ ] AC3: Данi вiдображаються у виглядi лiнiйних графiкiв з можливiстю вибору перiоду

## Технiчнi нотатки
- Використовувати бiблiотеку графiкiв (Chart.js, Recharts або аналог)
- Агрегацiя на бекендi для мiнiмiзацiї навантаження на клiєнтi
