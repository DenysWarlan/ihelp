# S-E11-02: Метрика часу першої вiдповiдi

## Контекст
Час першої відповіді є ключовим показником якості обслуговування та дотримання SLA (E07). Коректний розрахунок повинен виключати час пауз кейсу, щоб метрика відображала реальну швидкість реакції консультанта. Ця метрика є основою для оцінки ефективності та виявлення системних проблем у роботі команди.

## User Story
Як супервiзор, я хочу бачити точний середнiй час першої вiдповiдi консультанта, щоб контролювати дотримання SLA.

## Критерiї приймання
- [ ] AC1: Час першої вiдповiдi розраховується як рiзниця мiж першим повiдомленням людини та першою вiдповiддю консультанта у кейсi
- [ ] AC2: Метрика коректно враховує паузи кейсiв — час пiд час паузи не зараховується
- [ ] AC3: Значення вiдображається у зручному форматi (хвилини, години, днi)

## Технiчнi нотатки
- Timestamps беруться з E03 Chat
- Паузи кейсiв — з E02 Cases (статус PAUSED)

## Залежностi
- E03 (Omnichannel Chat) — timestamps повiдомлень
- E02 (Care Cases) — статус PAUSED для виключення пауз
- E07 (SLA Monitor) — SLA-пороги для порiвняння
