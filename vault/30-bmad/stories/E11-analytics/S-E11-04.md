# S-E11-04: Загальна аналiтика платформи — звернення та кейси

## Контекст
Координатор потребує загальної картини навантаження на платформу для планування ресурсів та оцінки ефективності. Статистика по зверненнях та кейсах (кількість нових, активних, завершених, середня тривалість) є основою для прийняття рішень про збільшення команди або перерозподіл обов'язків. Порівняння періодів дозволяє виявляти тренди.

## User Story
Як координатор, я хочу бачити загальну статистику по зверненнях та кейсах, щоб планувати ресурси та оцiнювати навантаження (QC-2).

## Критерiї приймання
- [ ] AC1: Дашборд показує: кiлькiсть нових звернень за мiсяць, кiлькiсть активних кейсiв, кiлькiсть завершених кейсiв
- [ ] AC2: Вiдображається середня тривалiсть кейсу (вiд створення до завершення)
- [ ] AC3: Данi доступнi з фiльтрацiєю по перiоду та з можливiстю порiвняння перiодiв
- [ ] AC4: Дашборд доступний тiльки для ролей Coordinator, Supervisor, Admin

## Технiчнi нотатки

- Середня тривалiсть рахується з урахуванням пауз
