# S-E11-01: Дашборд метрик консультанта для супервiзора

## Контекст
Супервізор потребує інструменту для систематичної оцінки роботи консультантів. Дашборд з ключовими метриками (час відповіді, кількість кейсів, неактивні кейси) дозволяє виявляти проблеми до того, як вони вплинуть на якість допомоги. Дані агрегуються з E02 Cases та E03 Chat, а доступ обмежений ролями (S-E11-07).

## User Story
Як супервiзор, я хочу бачити дашборд з ключовими метриками кожного консультанта, щоб оцiнювати якiсть роботи та вчасно виявляти проблеми.

## Критерiї приймання
- [ ] AC1: Дашборд вiдображає список консультантiв з метриками: середнiй час першої вiдповiдi, середнiй час мiж повiдомленнями, кiлькiсть завершених кейсiв за мiсяць, кiлькiсть кейсiв без активностi (QC-1)
- [ ] AC2: Метрики доступнi з фiльтрацiєю по перiоду (тиждень, мiсяць, квартал, довiльний дiапазон)
- [ ] AC3: При натисканнi на консультанта вiдкривається детальна картка з динамiкою метрик у часi
- [ ] AC4: Дашборд доступний тiльки для ролей Supervisor, Coordinator, Admin

## Технiчнi нотатки
- Данi для метрик беруться з E02 Cases (статуси, timestamps) та E03 Chat (timestamps повiдомлень)
- Розрахунок часу вiдповiдi повинен враховувати робочий/неробочий час

## Залежностi
- E02 (Care Cases) — статуси та timestamps кейсiв
- E03 (Omnichannel Chat) — timestamps повiдомлень
- S-E11-07 — рольовий доступ до аналiтики
