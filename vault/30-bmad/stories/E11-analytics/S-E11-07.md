# S-E11-07: Рольовий доступ до аналiтики

## Контекст
Метрики продуктивності консультантів є чутливою інформацією, доступ до якої повинен бути обмежений. Ролі Person та Consultant не повинні бачити аналітику, щоб запобігти несанкціонованому перегляду та потенційному тиску. Супервізор бачить тільки своїх підопічних, що забезпечує принцип найменших привілеїв.

## User Story
Як адмiнiстратор, я хочу щоб доступ до дашбордiв був обмежений ролями, щоб запобiгти несанкцiонованому перегляду метрик.

## Критерiї приймання
- [ ] AC1: Ролi Supervisor, Coordinator, Admin мають доступ до дашбордiв аналiтики
- [ ] AC2: Ролi Person та Consultant не мають доступу — при спробi доступу повертається 403
- [ ] AC3: Супервiзор бачить метрики тiльки своїх пiдопiчних консультантiв (якщо є групування)

## Технiчнi нотатки
- Middleware перевiрки ролi на рiвнi API

## Залежностi
- E01 (Auth & Identity) — рольова модель
