# S-E11-05: Загальна аналiтика — зустрiчi та курси

## Контекст
Зустрічі та курси є важливими інструментами допомоги, і координатору потрібно розуміти, наскільки активно вони використовуються командою. Статистика по зустрічах (E05) та курсах (E04) доповнює загальну картину роботи платформи та допомагає виявити недовикористані ресурси або зростаючий попит на певні формати допомоги.

## User Story
Як координатор, я хочу бачити статистику по зустрiчах та курсах, щоб оцiнювати використання цих iнструментiв командою (QC-2).

## Критерiї приймання
- [ ] AC1: Вiдображається кiлькiсть проведених зустрiчей за перiод
- [ ] AC2: Вiдображається кiлькiсть розпочатих та завершених курсiв за перiод
- [ ] AC3: Фiльтрацiя по перiоду (тиждень, мiсяць, квартал)

## Технiчнi нотатки
- Данi зустрiчей з E05 Meetings, курсiв з E04 LMS

## Залежностi
- E05 (Video Meetings) — данi по зустрiчах
- E04 (LMS) — данi по курсах
