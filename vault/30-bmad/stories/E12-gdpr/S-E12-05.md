# S-E12-05: Експорт даних (Art.20 — портабельнiсть)

## Контекст
Право на портабельність даних дозволяє людині отримати копію всієї своєї інформації у машинозчитуваному форматі. Важливо, що приватні нотатки консультанта виключаються з експорту (вони є professional notes), а watermark для Person містить тільки анонімізовані маркери для захисту ідентичності staff. Активні кейси також включаються, щоб людина мала повну картину.

## User Story
Як людина, я хочу отримати копiю всiх моїх персональних даних у машинозчитуваному форматi, щоб реалiзувати своє право на портабельнiсть (EDGE-64).

## Критерiї приймання
- [ ] AC1: У профiлi є кнопка "Експорт моїх даних" з пiдтвердженням
- [ ] AC2: Експорт генерує ZIP-архiв: JSON (профiль, iсторiя повiдомлень, прогрес курсiв) + вкладенi файли (зображення, документи) у вихiдному форматi
- [ ] AC3: Приватнi нотатки консультанта виключенi з експорту (professional notes)
- [ ] AC4: Watermark мiстить тiльки анонiмiзованi маркери — Person ID + timestamp (без iдентифiкаторiв staff)
- [ ] AC5: Активнi кейси включаються в експорт

## Технiчнi нотатки
- Staff-експорти зберiгають повний watermark (iм'я консультанта + timestamp)
- Термiн виконання — до 30 днiв згiдно GDPR
