# S-E12-03: Право на видалення (Art.17)

## Контекст
Право на забуття (right to be forgotten) є одним з ключових прав людини за GDPR. Каскадне видалення повинно охопити всі сутності (повідомлення, нотатки, файли, прогрес курсів), при цьому анонімізовані кейси зберігаються для статистики. Термін виконання 30 днів відповідає вимогам GDPR. Блокування при кризовому кейсі обробляється окремо (S-E12-04).

## User Story
Як людина, я хочу мати можливiсть запросити повне видалення моїх даних, щоб реалiзувати своє право на забуття (EDGE-63).

## Критерiї приймання
- [ ] AC1: У профiлi є кнопка "Запросити видалення даних" з пiдтвердженням дiї
- [ ] AC2: Пiсля пiдтвердження виконується каскадне видалення: повiдомлення, нотатки, файли, прогрес курсiв — протягом 30 днiв
- [ ] AC3: Кейси анонiмiзуються для збереження статистики (данi залишаються, але без прив'язки до особи)
- [ ] AC4: Людина отримує пiдтвердження прийняття запиту та орiєнтовний термiн виконання

## Технiчнi нотатки
- Каскадне видалення має охоплювати всi сутностi: messages, notes, files, course_progress, profile
- Анонiмiзованi кейси зберiгають структуру для QC-1/QC-2 метрик
